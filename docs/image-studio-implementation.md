# 当前工作台实现与边界

更新：2026-10-22。当前UI已经用户确认定稿，后续保持现有视觉。产品范围见[PRD](../PRD.md)，视觉参数只在[DESIGN](../DESIGN.md)维护，服务端契约见[生图API](image-generation-api.md)。本文记录实现职责，不追加旧方案或重复尺寸表。

## 页面与输入

首页提供共享草稿的创作输入、快捷用途与使用指南；开始创作只导航，不自动付费生成。首页不展示案例网格、模拟最近作品或其他示例内容。

首页创作输入在home-composer.tsx，布局在home.css。模型卡片与登录插画使用的bedroom、set、lavender图片仅作界面示例，不代表客户商品、供应商调用结果或用户上传；来源见[素材说明](design/studio-photo-prompts.json)。旧版未挂载的showcase数据、首页案例数据、配套CSS和六段MP4已经移除。

ReferencePicker统一文件读取、格式和大小提示、最多5张限制、清除、删除后引用重编号与图片预览；首页和工作台共用。ReferenceImageCard只接收图片、编号、预览及删除回调，不依赖业务store。图片完整展示、编号常显，删除入口在桌面hover/focus和触屏保持可操作；点击图片通过共享ImageViewer浏览。

ReferencePrompt统一普通文本与行内图片引用：输入@选择已上传图片，存储与提交仍序列化为@图片N；不宣称为供应商原生实体绑定。保留中文输入法、光标中间插入、Esc和键盘选择行为。

## 模型与工作台

前台只有gpt-image-2、gpt-image-2.5、nano-banana-2.1三个模型入口，均可按API目录选择1K/2K/4K。供应商变体映射由后端处理，不把五个供应商ID再显示为五张模型卡。模型卡片的封面、轮换、hover和说明遵循DESIGN，不作为模型能力实测证据。

工作台采用左参数、中结果、右历史索引。模型切换沿用当前提示词、参考图和参数；已提交快照不随草稿变化。提交成功只清空期间未再编辑的输入，页面切换保留客户端草稿。点击主图制作、家纺套图或智能裂变的生成按钮时，结果列表回到顶部、右侧历史索引回到第一项，新任务出现在首位；手机端历史是隐藏面板时不移动表单，重试和局部修图保持原位置。后台任务完成不会把用户带离当前页面。

GenerationHistory负责查询、空态、活动任务同步与预览编排；HistoryTaskMeta展示元信息和任务ID复制，ResultImage封装预览、下载和收藏，HistoryIndex负责右侧定位与我的素材入口，generation-status共用阶段标签和图标。任务编辑与重新生成集中在HistoryTaskActions，不在缩略图中再实现一次。

“重新编辑”直接回填历史输入并替换当前草稿，不弹框、不自动提交。“重新生成”通过ConfirmDialog，正文只显示本次积分。确定失败时在原任务中重试失败项、保留成功图片；结果不确定的旧尝试允许用户明确确认后在原记录重试：先退款并记录用户结束旧尝试的依据，新尝试再扣款；Worker仍不自动重发，旧结果迟到不会覆盖新尝试。所有历史操作请求失败只在顶部toast提示。详见[任务生命周期](task-lifecycle.md)。

提示词下方ReferenceThumbnails只展示提交快照input.referenceAssetIds中的上传参考图，无参考图则不显示；不使用生成结果补位。生成图位于结果区与历史索引，结果下方不重复展示图片编号。

## 图片浏览与局部编辑

- 生成结果和全屏我的素材中的图片打开ImagePreviewDialog：图片、任务信息、缩略图、下载及会话内收藏。信息区 ID 读取所属任务公开编号并提供复制，底栏不显示图片编号；内部图片 ID 和任务关联保持不变。局部编辑的新图使用修复任务编号，返回原图恢复原任务编号；无任务编号时显示“—”，不拿图片编号补位。
- 上传参考图、历史参考图和详情参考图使用共享ImageViewer，只展示浏览工具；按需加载，支持切图、旋转、缩放、拖动及关闭后焦点恢复。
- 我的素材 LibraryDialog 只在打开后请求成功生成的素材，不展示上传参考图；支持类型、模型筛选和分页。类型默认图片，并保留全部类型；当前两者均只有图片。素材类型与输入／输出用途分开记录，见 [数据库命名](database-naming.md)。嵌套预览关闭返回素材库，再关闭素材库返回入口。
- 全屏详情和素材库直接复用components/use-centered-dialog-motion，中心开关并在关闭动画结束后卸载；HeroUI负责模态和焦点。
- 独立/assets页面保留当前原图链接与下载入口，不因本次文档整理切换为另一种预览交互。
- 局部编辑通过lazy加载画布，保留原图、按区域描述生成新版本；接口、草稿与限制见[局部编辑](local-image-repair.md)。

## 数据、身份与账务

生图任务、历史和素材元数据从API查询、PostgreSQL持久化；图片由私有存储提供，不用样例伪装成功。TanStack Query管理服务端缓存，共享SSE连接更新任务；Zustand管理客户端草稿与交互。收藏和浏览状态不能宣称为服务端持久化。

企业账号密码接入JWT会话、访问token续期和退出；扫码、短信未接入，正式账号与本地开发身份分开，见[企业鉴权](enterprise-auth.md)。

个人中心是不设路由的弹窗，以页签呈现概览、积分明细、充值订单、会员与账号与安全，替代原个人信息、账号管理、订阅与账单弹窗；在当前页面上方打开，只挂载当前页签内容。账号管理展示真实资料与绑定可用状态；自助绑定、验证码和重置密码尚未接入，不模拟发送或保存成功。

组织主子账号共享钱包，每张2币、提交扣费、确定失败退回，账户中心读取余额和收支／充值记录。收支类型筛选只作用于已加载记录，不能声称筛选了全部历史。支付渠道与签到后续接入，见[企业钱包](enterprise-wallet.md)。不确定结果显示积分确认状态，不提前承诺退款完成。

请求错误共用useErrorToast去重；字段校验独立保留。生产配置、供应商、外部存储与支付是否可用，以部署配置和对应集成验收为准，不从界面或mock测试推断。
