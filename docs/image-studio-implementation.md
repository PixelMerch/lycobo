# 图片创作前端实现与验收

更新：2026-10-19。目标图：[三屏 UI](design/image-creation-flow.md)。

## 已实现

- `/`：统一紫色 HeroUI 应用壳、紧凑导航、常用入口、分类案例及会话内真实最近使用记录。
- 点击图片创作／开始创作：HeroUI Modal 模型选择层，只有 GPT Image 与香蕉模型；侧栏后 24px 内容 padding 锚定，外围不透明近黑背景。Escape 关闭、焦点恢复及弹层滚动由官方组件处理。模型卡片已按最新反馈改成桌面最大 200px、3:4 封面、整卡点击，删除进入创作按钮及第一张默认选中框；选择层内案例同样整卡点击查看。
- `/create/gpt-image`、`/create/banana`：左输入、中案例／历史、右索引。模型通过官方 Select 切换。每个模型有独立草稿，路由切换保留输入、参考图与输出选项。
- 本地图片读取：PNG／JPEG／WebP，单张不超过 10MB，当前前端上限 5 张；校验浏览器 MIME、大小与可解码性。读取失败或超出数量时保留已有图片。这些是前端体验约束，不替代后续服务端校验。
- 案例分类、预览、收藏、定位及真实 WebP 下载。案例引用采用追加要求；从案例弹层替换已有草稿需明确确认。
- `/assets` 仅显示当前会话草稿中的参考图；未声称已经上传或保存到云端。
- 任务中心与通知保持空状态，账户服务尚未开放。TK 保留分组导航并说明相应功能正在准备，AI 电商不冒充已实现工具。
- 移动端使用官方 Drawer 导航，参数、历史／案例、全局任务入口可达；支持减少动态效果。

## 实现与图稿的必要差异

图稿展示的已生成图片和历史在当前代码中明确表现为创作案例。首次进入默认案例库；真实生成历史为空。没有模拟队列、假进度或虚构完成状态。

生成按钮持续禁用并显示服务未开放；不能把干净的 UI 当成生产生成服务。比例、分辨率和张数仍是客户端草稿选项；没有声称供应商支持所列组合。尚未接入鉴权、付费生成、上传、任务持久化、扣费或发布服务。

Zustand 只管理会话内交互状态，刷新即重置；没有引入服务器数据的本地成功替代。TanStack Query 的基础 provider 保留，未添加虚假请求。真实服务接入后才会用其管理服务端数据。

## 删除与替换

旧 `features/design` 目录的页面、八模型列表、模拟任务、旧账户菜单、旧参考图 mention 编辑器与独立画布已删除；3080 行旧样式被新的紫色主题与布局替换。相应旧预览测试已替换为新流程的验收测试。

旧 `/design/*`、`/canvas`、`/history` 等地址仅保留轻量重定向到当前入口，不再加载旧页面。旧模拟任务 ID 不继续解释为真实任务。原独立 API、Worker、服务包及本地 design/ 归档未修改。

## 素材

`apps/web/public/studio/` 为内置 ImageGen 生成的独立家纺照片，包含奶油白卧室、三件套白底、浅紫卧室三组。不是 UI 截图裁切或真实客户成果。每组提供 960px 预览图及 480px 缩略图，网格不加载原始全分辨率图。完整提示词见 design/studio-photo-prompts.json。

## 验证

- `pnpm check`：lint、边界检查、全工作区类型检查、14 个单元测试及构建。
- `pnpm test:e2e`：8 个 Chromium 测试，包括三屏导航、模型限制、定位、关闭焦点、草稿隔离、上传失败／数量上限、收藏下载、不覆盖草稿、任务空状态和未知模型拒绝。
- 响应式检查宽度：320、390、768、1024、1440；桌面视觉复核 1584×993。页面无横向溢出，模型选择层在视口内。
- 不调用真实生图、计费或发布集成；数据库和队列没有变更，未运行集成迁移或生产操作。


## 紧凑卡片修订依据

本轮使用 finesse-ui 的产品密度与交互反馈方法，视觉参考为用户提供的艺栢竖版模型卡片及已确认的紫色 DESIGN.md。采用窄卡、竖向封面、短文案和整卡点击；不引入新的配色、组件系统或素材。命中范围包括图片创作选择层的模型与案例，不扩大改造首页或工作台。

卡片为 HeroUI Button，支持图片区域点击、Tab 与 Enter／Space；无嵌套交互元素。悬停和按压不位移，不默认把第一张标成已选中。一次导航即是完成反馈，无加载、成功或付费生成的虚构状态。


## 导航与分割线修订

用户反馈侧栏过密，现保持桌面 40px 行高，将条目间距由 4px 增至 12px，图标与文字间距由 8px 增至 12px，导航顶部留白为 16px。选中背景改为中性灰，业务图标和文字使用浅紫，右侧箭头始终是中性色。

图片创作、AI 电商说明层和 TK 分组入口均保留同一枚右箭头，展开时 CSS 旋转 180° 向左，收起恢复，160ms 过渡。TK 不再切换成另一枚向下箭头。减少动态效果沿用全局关闭动画规则。

图片创作选择层删除分类标题下与案例区上方的分割线，保留大外框与卡片边框；工作台工具栏也去掉额外分割线。此处参考用户给出的艺栢截图结构；未将艺栢网页的不可静态读取部分当成新的实测尺寸。


## 二级卡片圆角与状态

模型及案例卡片外框统一为 8px 圆角。封面上方两角为 8px、下方两角为 0，与下方文字区无缝拼接。悬停显示低对比度半透明白边框，仅文字区轻微提亮；按压及当前模型已选中时显示紫色主题边框，选中优先于悬停。首页首次打开不预选，进入模型工作台后重新打开选择层才标识当前模型。键盘焦点使用独立轮廓，边框宽度及卡片尺寸不随状态变化。具体 token 以 DESIGN.md 为准。


## 内容自适应选择层

选择层维持左上内容 padding 锚定，宽度由模型／案例较多组的卡片数量计算，最多四列；模型和案例统一 200px 列宽、12px 间距。外框在最后一张案例右侧保留 24px 内边距，不再横向铺满。窄屏限制最大可用宽度并换行，移动端仍为两列。封面与文字区 gap 为 0；悬停白色边框透明度降低至 32%，下方区域仅混入 6% 前景色，避免过强高亮。此处直接依据用户最新艺栢对比截图校正，线上网页为动态渲染，未将不可读取的页面声称为实测。


## 工作台边框精简

依据用户提供的工作台截图及此前艺栢三栏操作页参考，移除三栏外框、结果记录内框和元信息标签描边。左侧以单块柔和底板区分，中间与右侧使用页面底色；模型切换、画面要求以填充底色识别。参数改为共用底板的分组选项，去掉逐项描边，选中为中性灰底与浅紫文字。保留上传虚线、历史选中标记与键盘焦点。仅调整工作台 CSS，不改变模型草稿、上传校验、案例引用或禁用生成的行为。


## 工作台灰阶层次

根据用户最新艺栢参考截图修正低对比问题：保留少边框布局，将左侧参考图、画面要求及各参数组分别放在 #24242B 底色中，组内和组间均为 12px；外围 #17171B 与页面 #0F0F12 拉开层次。输入框为 #121216，参数选项底板为 #17171B，选中项进一步提亮并保留浅紫文字。作用域限制在 `.composer-panel`，不修改全站共享颜色，不给结果区与历史区加回外框。

工作台页面外层 padding 统一为 12px，与参数面板内边距及分组间距保持一致。仅对直接包含 `.workspace` 的主内容区设置局部变量；首页和模型选择层定位不变。


## 图片比例示意

图片比例选项按用户提供的艺栢截图加入矩形比例示意：1:1 正方形、3:4／4:5 竖版、9:16 长竖版、16:9 横版。图形由实际宽高比计算，在统一 32px 区域内显示，下方保留数字；整个 HeroUI 按钮可点击，保留原有 aria-label、aria-pressed 和独立模型草稿。图形 aria-hidden，避免重复朗读。分辨率与张数保持紧凑数字选项；未增加模型能力或自动提交生成。


## 比例展开与独立滚动

比例主区显示五个常用规格与“更多”，标题右侧显示当前值和展开箭头；使用官方 HeroUI Popover 显示扩展规格。选择后关闭并保留到当前模型草稿，主区回显扩展规格。删除空的“更多设置”及说明。桌面参数面板内的设置区独立滚动，底部生成操作保持可见；滚动边界使用 overscroll containment，左侧不随右侧页面滚动。手机仍为自然页面滚动。比例仅为前端草稿预设，不声称供应商已支持或真实生成已开放。


## 紧凑比例弹层

移除 4:5，扩展比例六项单行排列。弹层只由 Dialog 提供四边 12px padding，外壳与内部选项底板为 0，消除双重左右留白；标题下间距 8px、选项间距 6px。桌面总宽 368px，小屏选项保持至少 44px 点击宽度，必要时仅该行横向滚动。规范同步至 DESIGN.md。
