# 图片创作前端实现与验收

更新：2026-10-19。目标图：[三屏 UI](design/image-creation-flow.md)。

## 已实现

- `/`：统一紫色 HeroUI 应用壳、紧凑导航、常用入口、分类案例及会话内真实最近使用记录。
- 点击图片创作／开始创作：HeroUI Modal 模型选择层，提供 gpt-image-2.5、gpt-image-2.5-flare、gpt-image-2.5-sunburst、gpt-image-2、gpt-image-2-4K；侧栏后 24px 内容 padding 锚定，外围不透明近黑背景。Escape 关闭、焦点恢复及弹层滚动由官方组件处理。模型卡片已按最新反馈改成桌面最大 200px、3:4 封面、整卡点击，删除进入创作按钮及第一张默认选中框；选择层内案例同样整卡点击查看。
- `/create`：固定的图片创作工作台地址，左输入、中历史、右历史索引。模型通过官方 Select 在页面内切换，不改变路由；每个模型有独立草稿，切换模型保留各自输入、参考图与输出选项。旧地址 `/create/gpt-image` 会选中 gpt-image-2 再重定向到 `/create`；五个模型的带模型路径也会重定向到固定工作台地址。香蕉模型已移除。
- 本地图片读取：PNG／JPEG／WebP，单张不超过 10MB，当前前端上限 5 张；校验浏览器 MIME、大小与可解码性。读取失败或超出数量时保留已有图片。这些是前端体验约束，不替代后续服务端校验。
- 案例分类、预览与引用。案例引用采用追加要求；从案例弹层替换已有草稿需明确确认。
- `/assets` 仅显示当前会话草稿中的参考图；未声称已经上传或保存到云端。
- 任务中心与通知保持空状态，账户服务尚未开放。TK 保留分组导航并说明相应功能正在准备，AI 电商不冒充已实现工具。
- 移动端使用官方 Drawer 导航，参数、历史、全局任务入口可达；支持减少动态效果。

## 实现与图稿的必要差异

图稿展示的已生成图片在当前代码中保留为案例，只从模型选择层进入；工作台结果区仅保留“历史记录”，首次进入为空状态，不再提供案例库标签、筛选或右侧案例索引。没有模拟队列、假进度或虚构完成状态。

生成按钮默认显示“立即生成”：填写提示词、所选模型档位已启用且身份验证通过后可提交，参考图为可选。请求提交期间禁用按钮；响应不确定时显示“确认上次提交”，复用同一幂等编号。真实任务由数据库和独立 Worker 执行，历史和素材库显示持久化结果；参数仍按模型保存为客户端草稿，不修改已提交任务快照。服务未配置或失败时显示具体状态，不生成假结果。

Zustand 只管理会话内交互状态，刷新即重置；没有引入服务器数据的本地成功替代。TanStack Query 的基础 provider 保留，未添加虚假请求。真实服务接入后才会用其管理服务端数据。

旧 `features/design` 目录的页面、八模型列表、模拟任务、旧账户菜单、旧参考图 mention 编辑器与独立画布已删除；3080 行旧样式被新的紫色主题与布局替换。相应旧预览测试已替换为新流程的验收测试。

## 紧凑卡片修订依据

本轮使用 finesse-ui 的产品密度与交互反馈方法，视觉参考为用户提供的艺栢竖版模型卡片及已确认的紫色 DESIGN.md。采用窄卡、竖向封面、短文案和整卡点击；不引入新的配色、组件系统或素材。命中范围包括图片创作选择层的模型与案例，不扩大改造首页或工作台。

卡片为 HeroUI Button，支持图片区域点击、Tab 与 Enter／Space；无嵌套交互元素。悬停和按压不位移，不默认把第一张标成已选中。一次导航即是完成反馈，无加载、成功或付费生成的虚构状态。


## 导航与分割线修订

用户反馈侧栏过密，现保持桌面 40px 行高，将条目间距由 4px 增至 12px，图标与文字间距由 8px 增至 12px，导航顶部留白为 16px。选中背景改为中性灰，业务图标和文字使用浅紫，右侧箭头始终是中性色。

图片创作、AI 电商说明层和 TK 分组入口均保留同一枚右箭头，展开时 CSS 旋转 180° 向左，收起恢复，160ms 过渡。TK 不再切换成另一枚向下箭头。减少动态效果沿用全局关闭动画规则。

图片创作选择层删除分类标题下与案例区上方的分割线，保留大外框与卡片边框；工作台工具栏也去掉额外分割线。此处参考用户给出的艺栢截图结构；未将艺栢网页的不可静态读取部分当成新的实测尺寸。


## 二级卡片圆角与状态

模型及案例卡片外框统一为 8px 圆角。封面上方两角为 8px、下方两角为 0，与下方文字区无缝拼接。悬停显示低对比度半透明白边框，仅文字区轻微提亮；按压及当前模型已选中时显示紫色主题边框，选中优先于悬停。首页首次打开不预选，进入模型工作台后重新打开选择层才标识当前模型。键盘焦点使用独立轮廓，边框宽度及卡片尺寸不随状态变化。具体 token 以 DESIGN.md 为准。


## 内容自适应选择层

选择层维持左上内容 padding 锚定，宽度由模型／案例较多组的卡片数量计算，最多五列；模型和案例统一 200px 列宽、12px 间距。外框在最后一张案例右侧保留 24px 内边距，不再横向铺满。窄屏限制最大可用宽度并换行，移动端仍为两列。封面与文字区 gap 为 0；悬停白色边框透明度降低至 32%，下方区域仅混入 6% 前景色，避免过强高亮。此处直接依据用户最新艺栢对比截图校正，线上网页为动态渲染，未将不可读取的页面声称为实测。


## 工作台边框精简

依据用户提供的工作台截图及此前艺栢三栏操作页参考，移除三栏外框、结果记录内框和元信息标签描边。左侧以单块柔和底板区分，中间与右侧使用页面底色；模型切换、画面要求以填充底色识别。参数改为共用底板的分组选项，去掉逐项描边，选中为中性灰底与浅紫文字。保留上传虚线、历史选中标记与键盘焦点。仅调整工作台 CSS，不改变模型草稿、上传校验、案例引用或禁用生成的行为。


## 工作台灰阶层次

根据用户最新艺栢参考截图修正低对比问题：保留少边框布局，将左侧参考图、画面要求及各参数组分别放在 #24242B 底色中，组内和组间均为 12px；外围 #17171B 与页面 #0F0F12 拉开层次。输入框为 #121216，参数选项底板为 #17171B，选中项进一步提亮并保留浅紫文字。作用域限制在 `.composer-panel`，不修改全站共享颜色，不给结果区与历史区加回外框。

工作台页面外层 padding 统一为 12px，与参数面板内边距及分组间距保持一致。仅对直接包含 `.workspace` 的主内容区设置局部变量；首页和模型选择层定位不变。


## 图片比例示意

图片比例选项按用户提供的艺栢截图加入矩形比例示意：1:1 正方形、3:4／4:5 竖版、9:16 长竖版、16:9 横版。图形由实际宽高比计算，在统一 32px 区域内显示，下方保留数字；整个 HeroUI 按钮可点击，保留原有 aria-label、aria-pressed 和独立模型草稿。图形 aria-hidden，避免重复朗读。分辨率与张数保持紧凑数字选项；未增加模型能力或自动提交生成。

比例主区显示五个常用规格与“更多”，标题右侧显示当前值和展开箭头；使用官方 HeroUI Popover 显示扩展规格。选择后关闭并保留到当前模型草稿，主区回显扩展规格。删除空的“更多设置”及说明。桌面参数面板内的设置区独立滚动，底部生成操作保持可见；滚动边界使用 overscroll containment，左侧不随右侧页面滚动。手机仍为自然页面滚动。比例仅为前端草稿预设，不声称供应商已支持或真实生成已开放。

模型选择器从 18px／600 改为 14px／22px／500，内部 Select.Value 继承触发器文字样式；下拉选项为 14px／22px／400。全站 CSS 字号、行高、字重统一引用排版 token，零散 11px 辅助说明提升为 12px、15px 结果标题统一为 16px。移动端输入至少 16px 与品牌字号作为明确例外保留。完整角色表与约束见 DESIGN.md 第 4 节。未调整模型选择行为、控件高度、图片或灰阶层次。


## 比例弹层右侧对齐

宽屏使用完整比例分组的 DOM 引用作为 HeroUI Popover 定位锚点，右侧顶端对齐，间隔 32px，不再以小箭头为锚点覆盖主区；900px 以下改为下方定位。弹层标题统一为 13px／20px／500，主区和扩展项共用中性灰底色，删除主区额外的近黑条带，保留标准轻阴影。视口断点通过 useSyncExternalStore 订阅媒体查询，切换屏宽时沿用同一选择和焦点行为。


## 模型字段与底部操作

模型区改为左侧“模型”标签、右侧 HeroUI Select，分组 padding 与间距均为 12px，标签使用 13px，下拉值维持 14px。删除底部费用和服务未开放两段占位文案及 aria-describedby 悬空引用，移除对应样式。该阶段仅清理可见占位信息；当前按钮状态与真实服务行为以文末接入说明为准。


## 比例弹层标题与关闭反馈

比例弹层去掉外边框，保留灰色底和标准轻阴影。标题顶部为 12px，不再被同排关闭按钮的 40px 高度推低；关闭按钮绝对定位于右上角，点击区 44px、图标 22px，悬停为灰底亮图标、按压底色加深。主区与扩展比例选项也提供清楚的悬停反馈，所有状态不改变尺寸和定位。


## 紧凑模型下拉菜单

根据最新参考将模型触发器与菜单文字统一为 13px／20px／400，去掉选项两侧图标，使用纯文字和整行灰色选中背景。触发器宽 144px、桌面高 36px，菜单与触发器同宽；两者圆角均为 6px，菜单与列表不叠加 padding，行圆角为 0、桌面高 40px。模型分组只保留上下 8px、左右 12px 留白；手机点击高度仍为 44px。保留官方 Select 的选择、键盘和焦点行为，模型草稿切换逻辑不变。DESIGN.md 为最终排版标准，前文 14px 的修订记录已被本次规范替代。


## 模型菜单内容宽度

去掉触发器 144px 固定宽度，使用当前文字、箭头、8px gap 与左右 padding 自然撑开；菜单按最长选项自适应，至少与触发器同宽，不拉满参数卡片。原紫色横线是外偏移焦点轮廓被菜单裁切形成，现改为中性灰内描边，保留清晰的键盘焦点，不新增装饰性分隔线。DESIGN.md 同步为最终规则。


## 提示词与上传清除

输入、引用按钮和案例覆盖说明统一使用“提示词”；输入框聚焦不加高亮边框，以紫色光标提示。上传区改为“上传图片（最多上传5张参考图）”，右侧添加删除图标和清除按钮。一次清空当前模型全部参考图并清除上传错误，保留提示词与参数；读取中禁用，避免异步读取完成后重新添回。达到 5 张后隐藏添加按钮，单张移除或清空后恢复；原有文件与数量校验继续生效。


## 上传缩略图编号

上传缩略图的可见文字与无障碍名称改为“图片1、图片2…”；编号在图片底部显示，移除后自动按当前顺序重排，草稿中的原始文件名仍保留，素材库逻辑不变。单张删除按钮移到右上角外沿，使用白色叉号、1px 白边和半透明底色，悬停时加深背景；保留既有删除与移动端点击行为。


## 模型选择器无描边状态

模型触发器和选项统一去掉 outline、边框高亮和控件 box-shadow，覆盖 hover、原生 focus-visible、React Aria focus-visible 以及关闭菜单后焦点返回触发器。键盘焦点改用中性灰背景变化提示，菜单外层保留轻阴影；提示词输入仍只有紫色光标，无聚焦框。此次规则替代前文的灰色焦点内描边，作用域限定于模型选择器，不影响其他操作的焦点行为。


## 删除按钮与图片角部衔接

删除圆形从向外偏移 -6px 改为 top/right 0，与图片右上边界对齐。按钮底色和 3px 外隔离圈使用上传分组背景色，形成圆弧缺口，避免按钮直接叠在图片上或压住相邻图片；保留 1px 白边与 14px 白色叉号。手机维持 24px 可见尺寸，通过透明伪元素将命中区扩大到 44px。

删除按钮白色强度同步降低：默认边框 35% 白、叉号 65% 白；Hover 使用更深底色，边框和图标分别提至 60%／85% 白，保留背景色隔离圈。


## 分组标题顶部基线

模型标题原来受 36px 下拉框垂直居中影响，20px 标签行实际距上沿为 16px，大于上传区的 12px。现统一按文字行盒起点 12px 验收：模型行保留垂直居中，桌面上下 padding 从 8px 降为 4px，手机下拉框为 44px 时上下 padding 为 0；左右均为 12px，整行高 44px。其余分组使用 12px padding、标题靠上，比例箭头也不再推低标题。这样保持文字起点一致，同时模型标签与右侧值仍然对齐。


## 比例箭头与关闭按钮比例

展开箭头复用同一枚右箭头：关闭向右、打开旋转 180° 向左，160ms 过渡，关闭与选择后恢复；通过 aria-expanded 与 Popover 状态同步。关闭按钮仍有 44px 点击区，但可见悬停背景缩为 28px、圆角 6px，叉号为 18px。灰底仅画在内部底板，不把完整命中区域涂灰，减少动态效果时不播放过渡。

默认分辨率为 1K，适用于五个模型的新草稿；手动选择的分辨率随各模型草稿保留。当前参数仍为客户端交互，不代表接口已接通。

## 真实接口接入（2026-10-20）

上述早期“仅客户端”“无请求”等说明已被当前接入取代：工作台通过 TanStack Query 提交/查询真实生图任务、上传参考图，历史与素材读取组织范围内数据库。纯文生图不要求参考图。任务中心和右侧历史索引同步真实状态；输入草稿仍为客户端会话状态，页面切换不丢失，整页刷新不承诺恢复草稿。API、存储、幂等重放与本地身份说明见 [生图接入](image-generation-api.md)。
