# 当前工作台实现与边界

更新：2026-10-21。产品范围见 [PRD](../PRD.md)，视觉和交互尺寸见 [DESIGN](../DESIGN.md)，服务端行为及验收边界见 [生图 API](image-generation-api.md)。本文不重复维护逐次样式修改记录。

## 页面与交互

首页按已确认设计图重构为共享草稿的创作输入区、用途快捷入口、电商案例和真实最近作品。案例支持用途与品类组合筛选，复用仅带入提示词，覆盖前确认并保留上传图片。首页与工作台共用 ReferencePicker，最多 5 张；开始创作仅导航，不自动提交。最近作品只在企业登录后查询素材 API，只显示 output 缩略图，保留加载、错误重试与空状态。

首页当前使用既有 bedroom、set、lavender 缩略图展示家纺场景、套件与换色示例，atlas 资源保留但不再作为首页素材。示例不能当成供应商调用结果或用户上传素材。案例数据在 commerce-cases.ts，创作区在 home-composer.tsx，布局在 home.css，现有品牌 SVG 未修改。

创作区按小云雀浏览器实测值实现 1040×212px、28px 圆角、14px/21px 输入排印。提示词上方提供上传区，底部提供参数胶囊和白色圆形入口；参数使用 HeroUI Popover，支持模型、比例、API 可用分辨率及张数，切换模型迁移草稿。现阶段仅提供图片生成，移除视频入口与相关提示。placeholder 使用中性灰 #808080、400 字重。验收覆盖 320/390/768/1440/1920px、参数切换、草稿保留与仅展示图片生成入口。

“创作”选择层展示 gpt-image-2、gpt-image-2.5 两个可用家族及尚未开放的 banana；工作台继续保留五个供应商 ID 与规格选项。导航顺序为首页、创作、AI 电商、素材库，已移除 TK 专区。AI 电商的实际开放状态以页面和产品范围为准。选择模型和切换路由不会自动提交付费生成；选择层只保留模型区，案例浏览回到首页。

工作台采用左参数、中结果、右历史布局。模型切换沿用当前提示词与参考图；历史定位与编辑回填分开，重新生成需确认。页面切换保留客户端草稿，提交成功只清空期间未再编辑的输入。结果支持原图下载和会话内收藏；错误处理与调用核对以服务端状态为准。

企业账号密码已接入真实 JWT API，支持登录、刷新恢复会话与退出；扫码和短信未接入。正式企业账号与本地开发身份分开，配置与创建账号见 [企业鉴权](enterprise-auth.md)。

## 数据与素材

- 生图任务、历史和素材元数据由 API 查询，PostgreSQL 持久化；图片由私有存储提供，不以样例替代生成成功。
- 提示词草稿、收藏等客户端状态不宣称为服务端持久化。
- apps/web/public/studio 中的卧室、白底套件、浅紫卧室为合成样例，提供预览与缩略图；网格使用缩略图。[生成来源](design/studio-photo-prompts.json)保留，不冒充真实客户成果。
- 旧入口仅按路由配置做兼容跳转，不能据此推断旧功能仍存在。

## 验收入口

使用 [测试说明](testing.md) 中的 pnpm check、浏览器回归及隔离集成测试。代码、测试输出与实际服务端结果是功能证据；历史静态 UI 图不再作为实现或服务可用性依据。

参考图卡片封装在 `apps/web/src/components/reference-image-card.tsx`，通过 src、number、onRemove、isDisabled 属性复用；不依赖业务 store。首页与 create 页通过 ReferencePicker 共用卡片及文件校验逻辑，首页上传入口在前、缩略图 57.12px（54.4px 基础上增大 5%），首页编号为 10px / 14px，create 保持三列布局。

共享参考图使用 contain 显示完整图片；编号降低为白色 65% 透明度。桌面删除按钮仅 hover／键盘聚焦显示，贴合图片右上角覆盖显示，右上圆角与图片一致，无白色边框和阴影；触屏保留删除入口。

`ReferencePrompt` 为首页和 create 页共享的提示词输入组件，输入 @ 打开紧凑的已上传图片列表，选择后插入 @图片N 文本。引用沿用当前参考图顺序，不新增上传或 API 字段；不将文本引用宣称为供应商原生实体绑定。中文输入法组合期间不触发选择层，选择、Esc、键盘 Tab/Enter 和光标中间插入均纳入 UI 验收。

创建页历史任务的提示词与复制按钮下方只展示该任务提交快照 `input.referenceAssetIds` 中的上传参考图，按原提交顺序排列，点击查看参考原图；无参考图（包括未提供输入快照的旧记录）不显示此行，不使用生成结果补位。生成图片继续在结果大图区及右侧历史索引展示。


## 图片预览与资产管理

- 历史结果点击后在当前页面打开 HeroUI 全屏图片预览，按需加载原图；网格、历史索引和预览缩略图轨道仍加载缩略图。
- 预览提供放大、拖动、切换图片、下载原图及会话内收藏。图片说明、模型和时间跟随当前图片，资产列表实时更新不会改动已打开预览的顺序和信息。
- 历史索引标题打开资产管理弹层，支持按图片类型、模型筛选及分页加载；进入工作台时不提前加载资产列表。请求失败通过顶部 toast 提示。关闭嵌套图片预览后返回资产管理，关闭资产管理后恢复入口焦点。
- 失败结果不提供隐式重试，仅通过头部重新生成按钮确认后创建新任务。明确失败已在服务端事务中退款；结果待确认时仅提示积分状态正在确认，不承诺尚未发生的退款。
- `dialog-close`、`ReferenceThumbnails`、复制反馈和请求错误提示分别复用共享组件／工具，保持 HeroUI 的弹层、焦点与键盘行为。
- public/studio 下的六段 MP4 为样图派生的未使用版式演示资源，不参与真实生成或视频能力。

全屏图片预览与资产管理统一复用 `useCenteredDialogMotion`：从视口中心缩放、淡入，关闭时缩回中心、淡出，300ms 后卸载；不再横向滑入。焦点与弹窗仍由 HeroUI 管理。

模型选择弹层只遮盖主工作区，不覆盖 Header、全局侧栏及桌面右侧历史缩略图。遮罩与工作台网格共用历史轨道宽度变量，收起侧栏、宽屏和窄屏同步调整；边界由 CSS 确定，仍由 HeroUI Modal 负责交互。

模型选择层采用确认的 4:3 封面：桌面最大卡宽 256px、图片四角 20px、文字区最小 144px、卡间距 20px；无外描边，距侧栏和 Header 各 12px，贴左上按内容收紧。封面使用独立生成的通用示例，每组 3 张 WebP，自动交叉淡入；hover 放大 5.5% 并暂停轮换，键盘聚焦同样暂停。banana 不进入工作台、不提交请求。

模型入口介绍使用 #C8C8C8，完整展示模型定位、创作用途和视觉方向，不作绝对性能承诺；右上关闭按钮为 44×44px。

卡片宽度由 320px 缩小 1/5 至 256px，封面仍为 4:3（256×192px）；banana 补充创作方向说明并保留暂未开放状态，保持禁用。
