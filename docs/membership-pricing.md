页面新增的数字全部由价格表推导，不手写：标语“低至 ¥0.047 / 积分”取全部套餐与周期的最低单位积分价；周期提示“最低 N 折”取当前分类在该周期的最低折扣（个人年付3.8、季付4、月付5.2，团队年付3.5、季付3.7、月付4.8）。截图的“最低41折”“最低42折”与其卡片自身的3.8折不一致，未照抄。“积分单价最低”飘带按当前分类与周期计算（个人APEX、团队TEAM MAX）。“约生成 N 张图片”按本站每张2积分向下取整（BASE约655张），截图约按每张4积分换算并附视频条数，二者不同，本站不显示视频条数。
