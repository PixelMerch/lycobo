## 实现取舍

- 桌面按天分组的等高行由容器宽度计算：容器窄于720px（含手机和窄窗口）时改为两列瀑布流，类型筛选同时由分段按钮改为 Select。
- 从素材库打开的大图预览额外显示可复制的图片ID，替代旧素材库卡片下方的编号文字；尺寸、时间、下载与收藏也在预览中查看。历史预览仍只显示任务ID。
- 我的素材的收藏页签同样默认当前工具；该工具没有收藏时提供“查看全部收藏”。
- 收藏每位成员最多1000项，用于保证星标所用的收藏列表有界；超出时提示先取消部分收藏。
- “已加载 N 项”只统计已加载的分页，不推算总数；手机隐藏该计数。
