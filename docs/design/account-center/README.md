## 实现取舍

- 积分明细使用 HeroUI Table：时间列以“今天／昨天／日期 + 时:分”标明日期，代替图中的按日分组行；手机改为两行列表。
- 账户菜单去掉与积分卡片重复的“积分明细与订单”行，积分明细由卡片内胶囊进入。
- 次要按钮沿用站内 HeroUI secondary 样式（青柠文字），与其他页面一致。
- 收支说明只显示任务号或充值订单号；接口未提供工具名称，不推断“主图制作”等来源，也不提供尚不存在的任务深链。
- 作品缩略图只作展示，完整作品在素材库查看。
- 弹窗为 #1A1A1A，个人中心卡片、表格卡与筛选底改用充值弹窗积分卡的 #121212，保持卡片与底面的层次。
