## 本轮参考与取舍（2026-10-29）

用户否定横向排列“全部／创作／套图／裂变”，要求先搜索再设计。本轮通过 ego-browser 搜索并实际查看以下官方产品页面：

- [Photoroom 工具目录](https://www.photoroom.com/tools)：公开目录把商品背景、商品视频、照片优化和视觉生成等工具按用途分组。借鉴按业务目标归类的方式，不照搬其色彩、版式或功能数量。本次未核实其登录后的历史列表行为。
- [小云雀首页](https://www.xiaoyunque.com/home?tab_name=home)：实际页面将创作入口、项目资源及技能分开；项目区提供“筛选项目类型”和“查看全部创作历史”入口。借鉴将功能入口和结果管理分开的方式，不照搬 Agent 导航或营销首页。

据此，本提案采用“单个当前工具入口 + 可搜索的分类工具面板”；历史用“全部工具”下拉筛选。这两处是结合本站流程作出的设计决策，并非宣称参考站有完全相同的工作区。

## 两个层次

- **工作区是操作容器**：商品素材、工具表单、任务列表和任务索引共处同一页面。
- **主图制作／家纺套图／智能裂变是工作区里的工具**：左侧表单最上方只显示当前工具名称和“切换”，不再常驻任何工具 Tab。用户点击这个入口选择工具，选中后面板关闭并切换表单。
- **分类工具面板**：搜索和关闭固定在标题右侧，分类在下方横向排列，内容采用两列图片卡片。切换分类或搜索时面板高度固定，卡片区域内部滚动；hover图片在卡片内轻微放大，搜索聚焦保持中性灰。当前分为主图制作、套图与裂变、商品视频；新功能归入现有分类，确有新用途时才增加分类。列表内容滚动，不挤压工作区，也不增加侧栏一级菜单。未接入能力明确标记且不可执行。
- **历史筛选**：右上仅一个“全部工具”下拉，展开后可搜索并按分类选择具体工具；选择后按钮显示所选工具，选择“全部工具”恢复。筛选与切换工作工具是两种独立操作。

侧栏建议为首页、工作区、素材库。首次点击工作区默认进入“主图制作”的空态；再次进入恢复最近工具、草稿和列表定位。导航调整仍是提案，未修改现有“创作／AI 电商”路由或侧栏。

## 用户操作流程

| 工具 | 参数区 | 提交后的中间区域 |
| --- | --- | --- |
| 创作 | 商品素材、主图用途、制作要求、比例、分辨率、张数、图片模型 | 直接生成商品主图，进入统一历史 |
| 套图 | 商品主图、可选细节图、套图方案、拍摄视角、比例、分辨率、图片模型 | 按所选视角形成一组套图，进入统一历史 |
| 裂变 | 商品素材、变化目标、方案数量、比例、分辨率、图片模型 | 先生成创意清单，用户编辑／勾选确认后再提交图片任务 |
| 视频（后续能力） | 商品素材、视频用途、需求、画幅／时长、视频模型 | 分镜确认后生成视频，完成后同样进入任务列表 |

创作中的用途是场景主图、白底主图、活动主图等电商目标，不提供“自由生图”作为主定位。套图是独立工具，家纺多角度是其专用方案；与上一轮将家纺套图藏到裂变中的提案相比，本轮按用户最新要求明确分开工具入口。

## 结果放在一起还是分开

**同一工作区共用一条历史列表，按每次生成任务分组，不把所有图片散放在无限画布上。**

- 每组显示工具标签、模型展示名称、输出参数及本组结果；视频用视频预览卡，不混成图片缩略图。
- 默认“全部工具”。所有工具筛选都收在下拉面板内，不展示横向工具 Tab。新增工具只扩展下拉内容，按当前用户权限呈现；长列表在面板内滚动。
- 左侧切换工具不自动筛选、不清空列表；只有用户主动选择筛选项才改变可见记录。
- 右侧缩略图是任务索引，一格代表一个任务组；张数大于1才显示数量。它与当前历史筛选保持一致。
- 选中历史记录只定位任务，不改写当前表单；点击编辑才载入任务参数，存在未提交草稿时需要处理替换确认。
- 主动提交后可以定位新任务；后台完成不跳页、不夺走当前编辑位置。
- 图片详情继续使用独立编辑画布。素材库集中搜索、筛选、预览与下载所有有权访问的作品；不能因为列表统一而混淆资产权限。

“工作区”这轮是 UI 容器。是否建立多商品项目、商品档案及其数据库归属留待功能设计，不根据 UI 名称推断已存在项目持久化。

## 模型在哪里选择

**固定在左侧表单底部、主要生成按钮上方。** 模型入口始终可见，显示后台 Logo、展示名称和展开箭头；高级参数单独折叠，不再隐藏模型。

- 图片工具显示当前工具可用的后台启用模型；图中名称为已有展示名称示意，不写供应商请求标识。
- 创作、套图、裂变分别保留模型与参数草稿。已选模型被禁用或不兼容时，明确要求重新选择，不静默更换并提交付费请求。
- 后台若锁定某个专用工具的模型，入口应显示指定模型与只读状态；不假装允许切换。
- 视频切换为视频模型列表，不混入图片模型。当前视频未接入，所以图中显示待接入状态，不能用图片模型伪装可生成视频。
- 这些为后续能力约束建议，本轮没有变更模型配置、密钥、数据库、生成策略或计费。

## 状态、布局与边界

- 当前工具入口固定在左侧表单最上方，商品素材紧随其后。切换工具保留共享素材，各工具保留独立的未提交草稿和创意清单。
- 首次无素材时只有短空态和禁用主操作，不用大标题、三段步骤说明或营销卡片填空。
- 套图视角选择层只覆盖中间列表，不遮挡左侧输入或右侧任务索引；最多5列，高度跟随内容，取消／确认行为在接入时使用 HeroUI。
- 图中历史图片统一固定网格宽度，单张也不扩成整屏；多张保留下载全部，逐图保留下载、收藏及预览。
- 工具面板打开时锁定背景滚动，面板内可滚动；Esc、关闭按钮或点击外部可关闭。切换保留各工具草稿，焦点返回触发入口。搜索空结果用简短空态；键盘聚焦、选择及窄屏触控需在接入 HeroUI 时验证。
- 手机端工具选择面板占满可用宽度，分类改为单个分类下拉而非横向长条；表单与历史采用可切换的窄屏区域；模型选择在官方底部面板内展示，主动作留出安全区，触控目标至少44px。手机详细图稿可在桌面方向确认后展开，不把桌面缩略图当作手机验收。
- 生成中禁删，已结束任务可删；选中项删除入口常显，其余 hover／键盘聚焦显示；执行删除须二次确认并 toast 反馈。这些继承既有行为，不能因统一列表而丢失。
- 当前 UI 图不表达真实报价；接入时必须由服务端提供积分报价并在付费动作前展示。分析、生成、退款与不确定结果的逻辑需要另行设计、验证。

本目录保留已确认的设计依据；页面重构已更新 DESIGN.md、PRD.md 和业务页面，并验证原路由兼容、草稿保留及现有生成流程。接口、数据库和计费规则未在此次页面重构中调整。
