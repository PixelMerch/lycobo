## 产品组织建议

侧栏拟精简为首页、电商工作台、素材库。当前“创作”和“AI 电商”拟收进同一个工作台；这是本轮导航提案，尚未修改现有路由或侧栏。

工作台围绕同一个商品素材，内部切换“主图制作 / 商品裂变 / 商品视频”，而不是按通用文生图、图生图或模型品牌组织。家纺套图是商品裂变里的“家纺多角度”专用方案，与创意方案共用工作台，不再另占同级入口。

| 工具 | 用户操作 | 中间工作区 |
| --- | --- | --- |
| 主图制作 | 选商品素材、写用途或调整要求、直接生成 | 商品主图、历史结果 |
| 商品裂变 | 写变化目标、确认逐张提示词、选择后生成 | 创意清单 → 成套结果 |
| 家纺多角度（裂变方式） | 主图必选、详情图可选、选拍摄视角 | 视角选择 → 成套结果 |
| 商品视频（后续能力） | 选商品素材、描述视频需求、确认分镜 | 分镜脚本 → 视频预览 |

## 评审重点

- 商品素材固定在左侧上方，不因切换工具清空；每种工具分别保留未提交草稿。未提交的创意清单也保留。
- 只展示当前工具必要字段，模型下沉到“更多设置”。家纺原有默认模型策略不因此新增必填模型选择。
- 中间删掉营销大标题、三段步骤说明和说明卡片，直接承载清单、图片或视频。无内容时只显示短空态。
- 裂变确认在中间工作区编辑，不再弹出覆盖整页的长列表。逐条名称、提示词、勾选和删除都在清单里；底部主操作始终可达。
- 结果复用当前正方形图片网格、上方紧凑类型标签、下载全部和右侧缩略图；单张图不铺满整个宽度。
- 手机端商品素材与表单为可收起输入区，工作区按创意清单／结果切换；主操作固定在底部安全区，点击与键盘均可使用，不依赖 hover。
- 当前图里的张数、提示词、图片仅用于排版评审。分析、商品状态持久化、计费、任务提交、视频时长／分辨率与后端能力约束均未设计或改动；后续功能设计时必须按实际服务支持的值展示。

本提案未修改 DESIGN.md、PRD.md 或业务代码。评审确认后，再把选定方案归入正式规格并实施，原路由兼容、历史与付费行为需要单独验证。
