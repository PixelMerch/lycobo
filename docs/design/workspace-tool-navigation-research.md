# 工作区功能栏：参考与取舍

2026-10-30。用户要求优化不协调的图标与黄绿色高亮，并保持功能栏点击后左侧参数联动。本文仅记录依据；实施规格归入根目录 DESIGN.md。

## 已查看的 Refero 样式

- [Krea](https://styles.refero.design/style/50833119-cb36-4b75-b0cc-be48afea050a)：主方向。中性色导航让生成内容成为视觉重心；灰字到白字的状态变化，不将宣传图的色彩引入操作界面。
- [Linear](https://styles.refero.design/style/90ce5883-bb24-4466-93f7-801cd617b0d1)：只借鉴紧凑的图文节奏与低对比层级；不引入其字体、页面布局或营销组件。
- [Raycast](https://styles.refero.design/style/3b6a17f0-3bdf-418c-a95e-0b89e5a8b2f8)：只借鉴中性功能导航，不引入玻璃导航、键帽阴影、品牌红色或霓虹视觉。

以上为网站样式参考，不是这些产品操作界面的测量。直接操作 styles.refero.design 完成搜索并阅读对应样式。

## 决策锁定

| 决策 | 来源与角色 | 本站取舍 |
| --- | --- | --- |
| 操作区保持灰白中性 | Krea 导航与媒体主导原则、用户反馈 | 删除绿色图标底板、光晕和左侧面板微光；主题色按钮保持原样 |
| 紧凑图标＋文字 | Linear 的紧凑间距、项目 Tabler 约束 | 相机对应主图、拼图布局对应套图、魔法棒对应裂变；同尺寸同线宽 |
| 当前功能清晰可辨 | 用户要求、现有导航的中性状态 | 低对比灰底＋白字；不叠加图标底框，不依赖颜色表达状态 |
| 左侧内容联动 | 用户明确要求与现有路由 | 同步图标、标题、对应表单与历史；保留独立草稿，切换不发起生成 |
| 保持三栏与吸顶 | 当前已实现工作区 | 不更改上传、提示词、模型、比例、计费、右侧索引等行为 |
