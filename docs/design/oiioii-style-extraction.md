# OiiOii 浏览器设计提取

观察日期：2026-10-14。来源：[OiiOii 首页](https://www.oiioii.tv/zh/)。
通过用户指定浏览器检查首页、切换电商分类、打开已有单图项目查看画布。
只读取可见页面与 DOM / computed style，没有读取私有应用状态、请求接口或修改源站项目。
不保存源站账户信息、项目内容和素材到本仓库。

## 实测和观察

| 元素 | 来源证据 | 提取结果 |
| --- | --- | --- |
| body | computed style | rgb(13,13,13)，基础字号 14px，PingFang SC / sans-serif |
| 首页侧栏 | 可见 navigation 的 bounding rect | 宽 200px；高度跟随视口 |
| 行业切换条 | role=tablist computed style | #1A1A1A，99px 圆角，高约 39px |
| 主标题 | h1 computed style | 24px，600 字重，27.6px 行高；源站使用 MiSansVF |
| 输入区外层 | 可见输入区 DOM computed style | #151515，24px 圆角，12px 内边距 |
| 点阵层 | 页面背景 DOM computed style | radial-gradient，小点半径约 .6px；21px 网格 |
| 首页层次 | 实际截图 | 黑色页面、微弱边界、灰色激活项；中心输入，底部大图案例 |
| 画布结构 | 实际画布截图与可访问树 | 满屏点阵；项目胶囊、聊天大面板、右侧工具条、底部缩放悬浮 |
| 强调色 | 视觉观察，并非精确源色提取 | 高饱和玫红用于品牌与发送；少量黄绿色提示 |

以上“实测”仅代表当时页面 / 视口，不是源站完整设计系统。
源站截图只在当前会话中研究；用户提供的参考图不作为项目可分发资产。

## 在 lycoboai 中的转译

保留窄侧栏、黑灰分层、点阵、圆角输入、悬浮画布与少量玫红。
业务从视频 Agent 转为“商品图 + 描述”：减少模型 / Agent 概念，突出商品、任务、结果。
画布的生成面板按用户之前确认的工作习惯放右侧；不用复制源站的左侧聊天方向。
增加持久任务中心的产品规格、跨项目任务抽屉和新结果入口，避免把记录藏在聊天里。
不采用源站推广、积分营销或虚构账号；当前预览的状态明确标为示例。

## 素材来源

`apps/web/public/design/product-studies.png` 由本次内置 imagegen 工具生成，四宫格商品摄影。
界面图片通过 CSS background-position 展示四个象限；下载演示使用浏览器 Canvas 导出相应象限。
这些不是源站图片，也不是用户真实生成记录。完整提示词见 [asset-prompt.md](asset-prompt.md)。
UI 图来自本地 React 页面的浏览器截图，不是生成式整页图片贴在应用上。

## 后续视觉调整

按用户最新参考，lycoboai 的品牌、主操作、通知与焦点改用汽水绿 #A8FF00；源站玫红仅作为观察记录，不再是实现配色。案例卡改为 180–230px、4:3 图片与单行标题，保留深色点阵和 HeroUI 圆角。
