# 统一图片画布交互依据

2026-10-22。仅记录已确认的交互取舍，最终尺寸、颜色及行为均以 [DESIGN.md](../../DESIGN.md) 为准。

## 参考与约束

- 用户提供的局部编辑截图及确认：打开即为画布；桌面工具栏在画布右侧竖向常驻，手机在顶部横向排列；背景采用灰色点阵，鼠标经过产生白色扩散波纹。进入修复只切换中间栏，避免页面跳转和左图位移。
- [现有参考站研究](reference-style-dna.md)：保留图像优先和克制的暗色层次，不引入对方的荧光绿、品牌和文案。
- Refero Design 内置 Motion & Micro-interactions Guide：以连续性、操作反馈和层级为动效依据，模式切换只淡入新信息栏。在线样式与屏幕搜索尝试返回 NO_SUBSCRIPTION，因此没有声称获取在线设计样本。
- 现有项目工作区、HeroUI组件清单及用户定稿：沿用三栏、紫色主题、13px滑块和全屏关闭规格，不新增交互基础库。

## 决策

| 决策 | 原因 | 验证 |
| --- | --- | --- |
| 同一图片节点＋透明选区层 | 模式切换时位置、缩放及原图不跳变 | 浏览器检查节点仍连接、几何和变换一致 |
| 桌面工具独立靠右垂直居中，手机横向；左画布点阵与鼠标波纹 | 按用户新确认的背景参考实现；仅提亮点，不移动图片或干扰选区 | 桌面／窄屏、波纹消退、减少动态效果与原有画布交互检查 |
| 修改区域编号与说明卡片对应，隐藏坐标及重复原图／输出参数 | 多区域修改时可以定位和复查 | 绘制、原图坐标换算、撤销与重做测试 |
| 按图片保留草稿 | 用户可以切图比较后回来继续 | 跨图片切换和恢复草稿测试 |
| 仅信息栏切换，右侧列表不变 | 保留查看上下文和结果导航 | 详情／修复进出及列表定位测试 |
| 适应画布共用底栏 | 任何模式下都能恢复完整视野 | 重置缩放和平移测试 |

真实生成仍通过既有后端任务接口。浏览器回归使用明确的接口 fixtures，不代表真实扣费或模型调用。
