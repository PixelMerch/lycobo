## 3. 可复用的三条规律

1. **深色是共同底座，强调色只做少量信号。** 两站都没有大面积品牌色背景；艺栢的荧光绿只出现在按钮和数字上，小云雀的紫色只出现在文字与细边框上。强调色面积越大，越像模板站。
2. **字号层级由页面性质决定，不分站统一。** 艺栢控制台最大 24px，靠密度和封面建立层级；小云雀营销页用 40px / 300 建立呼吸感。同站里营销页与控制台应采用两套排印尺度。
3. **圆角与边框承担不同的「软硬」语气。** 艺栢用 0–6px 直角表达工具感；小云雀用 12–24px 与胶囊表达消费级亲和。两者混用会显得没有主张，应按区域择一。

## 4. 给 lycobo 的候选方向

三个方向都保留现有紫色品牌资产与 HeroUI 组件边界，只改 token 与排印，不引入第二套组件或新图标库。

### 方向 A：控制台优先（偏艺栢）

- 近黑 `#0F0F0F` 壳、`#191919` 卡片、0–6px 圆角、14px 密排、荧光绿或紫色小面积强调。
- 优点：与现有深色规范改动最小；工具密度、封面即示例的结构已在本站存在。
- 风险：品牌辨识度弱，接近通用 AI 工具站；荧光绿会与已确认的紫色体系冲突。

### 方向 B：品牌页优先（偏小云雀）

- 黑／白分区、40px / 300 大标题、少量衬线点缀、12–24px 圆角、薰衣草紫 `#A98CFF`。
- 优点：Agent 感强，适合首页、登录与空状态；紫色与现有 `#8B5CF6` 同族，迁移成本低。
- 风险：浅色区与现有深色工作台并存，需要明确「营销页浅、工作台深」的边界，否则整站割裂。

### 方向 C：深色壳 + 编辑感排版（推荐）

| 区域 | 取值 | 来源 |
| --- | --- | --- |
| 页面／侧栏 | `#0B0B0E`–`#0F0F0F` | 两站 |
| 卡片／分组 | `#191919`、`#252525` | 艺栢 |
| 常驻强调 | 紫色 `#A98CFF`（由 `#8B5CF6` 上移一档） | 小云雀 |
| 主操作 | 保留已确认的 `#BAA4FF → #8B5CF6` 纵向渐变与 `#09070D` 前景 | 本站 |
| 营销页标题 | 40px / 300 / 48px，点缀词可用衬线 | 小云雀 |
| 工作台字号 | 13–14px / 400–500，最大 24px | 艺栢 |
| 圆角 | 工具卡 8–10px、弹层 16px、按钮胶囊，不保留 0px 直角 | 折中 |
| 图层 | 弱阴影 + 1px `rgba(255,255,255,.08)` 细边 | 两站 |

理由：电商 SaaS 的工作区需要艺栢的密度，首页与登录需要小云雀的呼吸感；两者共用同一深色底与同一强调色，只是排印尺度不同，不会形成两套视觉。

## 5. 不采用的部分

- 不复用对方的自托管字体（AlibabaPuHuiTi-3、MiSans Light Embedded、Cormorant Garamond Agent Embedded）与图片素材。
- 不复制小云雀的全屏影像轮播、积分促销弹窗与第三方登录品牌。
- 不引入荧光绿作为第二强调色；语义色仍只用于成功、警告、错误。
- 不把 40px 标题带进工作台，也不把 14px 密排带到首页首屏。

## 6. 决策与落地

2026-10-20 用户确认采用**方向 C**，已落到本页与 DESIGN.md 的 token 与排印规则：

- `--accent` 由 `#8B5CF6` 上移为 `#A98CFF`；主操作渐变两端固定 `#BAA4FF → #8B5CF6`，不再引用 `var(--accent)`。
- 新增 `--text-display / --leading-display / --weight-light`，首页标题使用 40px / 48px / 300。
- 入口卡片圆角由 12px 收敛为 10px，边框收为 `#FFFFFF14`。
- 工作台字号、密度、圆角与三栏布局不变。

后续如需再调，先改 DESIGN.md 再改样式文件，不直接在生产页面覆盖。
