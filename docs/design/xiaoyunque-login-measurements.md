# 小云雀登录样式实测与应用规范

2026-10-20，按用户要求在 Chrome 打开 https://www.xiaoyunque.com/，点击“登录领积分”，读取实际 DOM 与 getComputedStyle；点击手机号字段后再次读取聚焦样式。以下均为 CSS px，不从截图像素反推，不代表未访问页面或其扫码界面。

| 元素 | 官方实测 | 本站应用 |
| --- | --- | --- |
| 标题字体 | -apple-system, system-ui, SF Pro Display, Helvetica Neue, sans-serif | 登录标题及副标题相同字体栈 |
| 控件字体 | PingFang SC, Hiragino Sans GB, Microsoft YaHei, Noto Sans SC, sans-serif | 登录输入及按钮相同字体栈 |
| 登录标题 | 30px / 42px，400，#000 | 同值；窄屏 24px |
| 副标题 | 14px，400，rgba(0,0,0,.4) | 同值，行高 20px |
| 输入文字 | 13px / 20.4295px，400，#000 | 同值；移动端 16px 避免系统缩放 |
| 输入几何 | 高 40px，左右 padding 16px，圆角 12px，无边框 | 同值；触屏命中至少 44px |
| 输入背景／placeholder | rgba(0,0,0,.05) / rgba(0,0,0,.25) | 同值 |
| 输入聚焦 | inset 0 0 0 1px rgba(0,0,0,.15)，无 outline，黑色光标 | 同值；InputGroup 只在外壳显示一次 |
| 主按钮 | 13px / 20.4295px，600；高 40px、padding 16px、圆角 120px、黑底白字 | 同值；触屏至少 44px |
| 第三方登录按钮 | 14px / 22.001px，600；40px 高，120px 圆角，白底，1px rgba(0,0,0,.08) 边框 | 微信、手机号、企业账号入口共享相同规则（行高取 22px） |
| 发送验证码 | 13px，500，#8360EC，padding 16px | 同值 |
| “或” | 10px / 15.715px，rgba(0,0,0,.25) | 字号颜色同值，行高取 16px |

官方实测表单宽 320px、右栏左右 padding 40px。本站继续保留已验收的 920px 总宽与右栏 padding 36px，以容纳本站较长的英文品牌名和双入口；这属于布局差异，不能声称整站逐像素相同。微信扫码、手机号与企业账号是本站业务入口，官方当前弹窗仅测得手机号和抖音入口。本站默认扫码、未接入状态、密码校验和关闭清除逻辑保持真实。

本轮将字体、字重、颜色与控件形态精确应用到登录弹窗；未将官网营销标题字号或浅色登录颜色扩散到深色创作工作台。其他页面需要以对应的实际页面组件为证据，不能把登录页的 30px 标题或 13px 输入字体视为全站所有组件字号。
