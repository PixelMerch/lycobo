# 积分、充值与会员入口参考

2026-11-02使用ego-browser查看[小云雀](https://www.xiaoyunque.com/home?from_page=xiaoyunque_landing_page&tab_name=home)与[Oii价格页](https://www.oiioii.tv/zh/price)，仅作视觉研究，未购买、订阅或修改账户。本站采用值已写入唯一规范[DESIGN.md](../../DESIGN.md)。

## 观察

- 小云雀Header余额与会员为相邻独立操作区；余额入口可展示积分余额、最近记录和明细入口。积分超市打开独立“购买积分”框，单选包围绕额度、价格组织，底部为统一购买动作。当前浏览器下充值框实测548px宽、738px高、12px圆角、#2F3036底、36px 32px 32px内边距。
- 小云雀会员内容与积分包分开，按周期比较套餐、赠送积分和使用定位，未与积分账单混在同一组三个页签内。实际点击会员后内容在当前站点内呈现；不据此声称其URL一定变化。
- Oii未登录首页可打开公开价格页；按个人/团队/企业与周期组织套餐，方案卡层级清楚，充值另设入口。公开页有促销banner、倒计时、多个套餐和不同强调色。未验证登录后的余额、支付或到账流程。

## 本站取舍

- 一个Header胶囊、积分与会员两个主点击区：依用户要求，积分点击直接打开充值，桌面hover在下方提供明细入口，键盘向下键可访问。手机在充值框内提供明细按钮。
- 充值框最多640px、三档紧凑单选包；会员改为独立懒加载页面，两档并列，保留返回创作与草稿。
- 继续使用青柠绿#A8FF00、现有字体及控件密度、官方HeroUI交互组件。余额与收支读取真实企业钱包，价格、赠送额度未确认，全部待公布且购买禁用。
- 不复制竞品商标、紫/粉配色、价格、赠送或限时承诺，不加入仅会员能购买积分的限制，不制造个人会员状态、到期日或成功交易。
- 不保存竞品私有账户明细截图或数字到账单样例中。浏览器截图仅为临时核对，不作为网站素材。
