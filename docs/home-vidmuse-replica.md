# 首页 vidmuse 复刻页说明与改进建议

更新：2026-11-12。

本文记录当前首页复刻页的范围、与采集源的差异，以及后续改进建议。它描述的是**视觉原型**，不是生产能力说明；正式上线前仍需产品、视觉和法务确认。`DESIGN.md` 仍是全站视觉规范，本页目前是用户明确要求下的临时例外。

## 当前状态

- 首页路由 `/` 渲染 `apps/web/src/features/home/vidmuse/vidmuse-landing.tsx`，页面自带 header、footer 和 vidmuse 主题，应用壳顶部栏在首页隐藏。
- 主题色使用采集页的橙红 `#FB5123`（悬停 `#FC744F`），按钮文字和图标为白色；页面底色为黑色。
- 媒体资源在 `apps/web/public/vidmuse/`，组件和样式在 `apps/web/src/features/home/vidmuse/`。
- 首屏在开发环境挂载本地采集的 Unicorn Studio 场景（`apps/web/.vidmuse-scene`），生产构建使用同源循环视频 `hero-bg.mp4` 与静态封面兜底；遵循 `prefers-reduced-motion`。
- 登录、上传、生成、计费、导航和语言切换目前没有接入业务；只保留页签切换、轮播、视频播放、点赞、模板填入等展示交互。
- 旧首页的创作框、模式页签、灵感墙和快捷入口组件已移除；灵感库、登录等仍被其他页面使用的代码保留。

## 改进建议

### P0：上线前必须确认

1. **把 VidMuse 文案换成 Lycobo 真实能力**  
   当前页面仍保留竞品广告研究、Campaign Kit、ROAS、Lower CPA 等 VidMuse 演示内容。上线前应改为 Lycobo 的商品图能力，或明确标注为演示数据，不能把尚未实现的能力写成产品事实。

2. **确认素材和第三方运行时授权**  
   采集页的图片、视频、Logo 和 Unicorn Studio 运行时属于参考素材。正式发布前确认再分发权利；其中 4 张补充模板图来自现场素材源，同样需要复核授权。

3. **确定首页壳层与品牌决策**  
   现在首页使用复刻页自己的 VidMuse header/footer，并隐藏 Lycobo 全局顶部栏。如果保留独立头部，需要补齐语言、登录、导航和手机菜单；否则应换回 Lycobo 壳层并更新 DESIGN。

### P1：视觉与交互保真

4. **确认首屏场景授权与发布方案**
   开发环境已挂载采集包的 Unicorn Studio 场景，生产构建使用同源循环视频兜底。场景、视频和模板图的再分发授权仍需确认；若要生产环境也使用实时 Canvas，需要补齐场景包和运行时授权。

5. **补齐工作流的可访问语义**  
   采集页使用 `role=tablist` / `role=tabpanel`；当前实现用 ToggleButtonGroup 完成视觉切换。建议改成 HeroUI Tabs 或补全 tab 语义、方向键切换和 `aria-controls`。

6. **复核响应式与减少动态**  
   固定按采集视口 `1440×900` 和手机 `390×844` 目测；检查两侧黑边、Impact 内缩、模板横向滚动和所有动画在 `prefers-reduced-motion` 下的静态回退。

7. **恢复页脚微信入口的弹层行为**  
   采集页的微信图标是带 `aria-expanded` 的弹层按钮，当前是普通链接。若保留社交入口，应改成正式 Popover 或明确标注为不可用。

### P2：接入真实业务

8. **创作框接入项目能力**  
   将输入框、参考图、模型/比例设置和提交按钮接到项目草稿、登录门禁、上传、积分和任务提交；未接入前不要显示“已开始生成”等成功提示。

9. **导航、CTA 和语言切换接入项目路由**  
   把模板 Remix、Start Creating、登录、Try Now 和各导航项接到真实页面；切换语言时保留首页状态，并补全中英文案目录。

10. **补齐页面元信息**  
    根据最终内容设置页面标题、描述、OG 信息和主题色；不要把采集页的统计脚本、像素或第三方分析代码带入项目。

### P3：性能与验证

11. **压缩首屏媒体**  
    当前公开资源约 12 MB，含多段视频。上线前按视口生成响应式图片、延迟加载非首屏视频，并评估首屏 Canvas 与视频同时播放的 CPU/GPU 成本。

12. **建立视觉回归基线**  
    通过手动 GitHub Actions 浏览器 CI 覆盖首屏、工作流、模板轮播和 Impact 的关键断点；本地不运行浏览器 E2E。断言重点放在布局尺寸、可见状态和 reduced-motion，而不是像素级截图。

13. **清理原型残留**  
    在功能接入后复查 `features/home/vidmuse` 的未使用交互、重复媒体和临时样式；不要保留无法说明来源的素材或演示接口。
