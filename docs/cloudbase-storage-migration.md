## 目标权限与代码

使用 CloudBase PG 原生云存储，不使用传统 NoSQL `uploadFile` 或 R2/S3。私有桶 `public=false`，单对象最多 32 MiB，仅允许 PNG/WebP；`storage.buckets`、`storage.objects` 保持 RLS，未给 anon/authenticated 创建直接读写策略。

通过服务端专用资源凭据进行迁移和后续对象操作。代码中的私有桶适配固定 CloudBase 网关，不转发凭据到重定向地址；配置 CloudBase 后不回退旧 R2/S3。业务访问仍须由 API 校验企业身份、组织归属及资源签名。配置和凭据管理见 [CloudBase 部署](cloudbase-deployment.md)。

目标通过 PostgreSQL 元数据再次核对：桶中 464 个对象，无临时测试文件，私有标志及大小上限正确。此元数据统计与逐对象下载验证结合使用；仅有存储记录不作为字节复制成功依据。
