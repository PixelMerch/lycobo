# LYCOBO 首页内容与素材方案

2026-11-13 · 待评审。本文对应当前首页原型，记录内容替换、真实功能入口和候选素材。现行视觉规范见 [DESIGN.md](../DESIGN.md)。路线与能力以 [PRD](../PRD.md)、[套图计划](product-variation-plan.md) 和 [复制爆款](style-match-and-reference-waiting.md) 为准。

## 1. 首页主线

第一版面向跨境家纺运营，首屏让人看懂「我能把手里的床品图做成什么」。用雾蓝菱格绗缝被和两只同款枕套贯穿主案例，搭配暖白卧室与浅木家具。上一轮的跨品类样图保留作后续候选。首页以成片、参考图和可点的功能名称为主，文案缩到一行标题、一句说明和操作标签。

保留现在有辨识度的视觉结构：暗色氛围首屏、左创作右作品、深浅区块切换、横向卡片与页尾 CTA。素材换成同一商品的成组图片。右侧浮层承担说明原图、细节或交付画幅的作用。

## 3. 首屏对比动画

第一帧从普通床品照片切换到一张完整的卖点商品图。[查看原图与成片](design/home-lycobo-assets/blue-quilt-product-pair.jpg)。同一套雾蓝被保留菱格绗缝、包边与两只枕套。成片重新安排商品位置，采用暖色窗光，在顶部排出西语标题、套件组成和带引线的圆形绗缝特写。版式参考了用户给的卖点图，交付图由 `gen-image` 独立生成。图上的卖点限定为可从样图确认的套件组成和绗缝外观。

- 两张图使用同一个 4:5 展示框。完整商品图含顶部标题和细节圈，移动端也按全图展示。
- 首次先展示原图约 1 秒，竖线用约 1.2 秒揭开成片，随后停在成片。切回此帧时由用户选择重播。
- 支持拖动、点击定位与键盘方向键，操作时暂停轮播。保留「原图」「商品图」标签，减少动态模式用按钮切换两张静态图。
- [扫线动画预览](design/home-lycobo-assets/blue-quilt-product-reveal.gif) 用于评审节奏。首屏正式接入时使用两张静态图实现可拖动对比。

## 5. 后续接入与验收

1. 先换页头页脚、首屏文案、背景和三帧示例。检查桌面 1440×900、手机 390×844，特别看首帧裁切、文字对比、静态回退和导航入口。
2. 再换案例横滑、三步套图、家纺拼贴和模板卡。首屏优先加载背景与首帧，其他示例按需加载；图片带固定尺寸，避免切换时跳动。
3. 最后接路由、草稿带入和登录。核对页面中英文、键盘操作、取消或失败时草稿保留、付费提交留在现有工作台。清理已替换的 VidMuse 文字、品牌图形、第三方演示媒体和数字标签。页面标题、描述与分享图随最终文案更新。
