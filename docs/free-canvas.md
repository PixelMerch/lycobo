# 自由画布

自由画布位于 `/free-canvas`，代码在 `apps/web/src/features/free-canvas/`。页面提供一张可缩放、可平移的画布，用户可以放入本地图片、文字和便签，也可以调用现有生图任务，把结果直接放到画布上。

## 范围与边界

- 生成走既有 `POST /api/v1/image-tasks`，与主图制作共用模型、分辨率、积分和登录门禁；页面不新增接口、模型或计费逻辑。
- 每次生成请求 1 张，提交后由页面轮询 `GET /image-tasks/:id`，取第一张成功的 `output_asset_id` 放入画布；失败或超过 4 分钟停止等待，不重复提交。
- 本地图片只生成浏览器 `blob:` 预览，不上传服务器；画布内容保存在本机 `localStorage`（键名 `lycobo:free-canvas:items`）。刷新后仍可继续，但换浏览器或清空站点数据会丢失。
- 与工作区一致，页面受现有登录门禁保护；未登录访问会先到登录页并保留返回地址。移动端工具按钮保持 40px 图标与 44px 触控行高。

## 技术选型

画布使用已安装的 `konva` 与 `react-konva`，没有引入新的画布依赖。

| 方案                | 许可                     | 结论                                               |
| ------------------- | ------------------------ | -------------------------------------------------- |
| Konva / react-konva | MIT                      | 采用；与现有项目依赖一致，可商用且无许可密钥       |
| Excalidraw          | MIT                      | 适合手绘白板，但其图形语言与商品图排版不符；未采用 |
| tldraw SDK          | 源码可见，生产需商业许可 | 未采用，避免生产环境的许可密钥与费用               |
| Polotno             | 商业 SDK                 | 未采用，会引入付费依赖                             |

## 结构

- `free-canvas-page.tsx`：页面组合、本地文件选择与本机存储同步。
- `free-canvas-toolbar.tsx`：工具切换、缩放与视图重置。
- `free-canvas-stage.tsx`：Konva 舞台、图片加载、选择、拖动、变换与滚轮缩放。
- `free-canvas-panel.tsx`：选中项操作与模型生成面板，包含任务轮询。
- `free-canvas-state.ts`：Zustand 画布状态，只保存编辑态。
- `free-canvas-storage.ts`：本机存储的读取与写入，带结构校验。
- `free-canvas-messages.ts`：中英文文案。

## 交互

- 工具：选择、移动画布、添加文字、添加便签；添加文字后自动回到选择工具。
- 选择：点击节点选中，拖动移动，四角变换框缩放，滚轮以指针为中心缩放（0.25–4 倍）。
- 平移：手形工具，或在空白处按住 Alt 拖动。
- 层级与副本：上移、下移、复制、删除；复制会偏移 32px。
- 减少动态效果：页面没有持续动画，缩放与拖动都是即时响应。

## 入口

顶栏“自由画布”文字入口（桌面）与手机抽屉中的同名入口都指向 `/free-canvas`；路由在 `apps/web/src/app/router.tsx` 内按既有语言前缀加载，路径常量在 `free-canvas-path.ts` 中维护。

## 验证

- 单元测试：`apps/web/src/features/free-canvas/free-canvas-state.test.ts`（新增、复制、层级、缩放边界）与 `free-canvas-storage.test.ts`（存取、脏数据、非法 JSON）。
- 生成链路依赖真实登录、积分与供应商，本地未配置登录与生图服务时无法端到端验证；页面会按既有门禁先跳转登录。
