# Givingli 首页设计拆解

观察日期为 2026-11-16。用 Ego Browser 浏览公开首页，查看了 1437 × 886 CSS px 的桌面视口和 390 × 844 CSS px 的移动视口。尺寸、字体和色值取自页面计算样式，观感和动效判断根据滚动、截图与控件观察。产品文案与数字按 Givingli 首页展示理解。 [Givingli 首页](https://givingli.com/)

## 风格判断

Givingli 是**以当代纸品和贺卡目录为视觉线索的消费品牌落地页**。编辑式大标题、纸张色底、成组的贺卡、印刷品编号和手写引语，让网站像一册可以操作的礼物目录。干净的吸顶导航、搜索、商品入口和流程演示，把这种情绪引向挑选与发送。

- **视觉中心是商品，也是叙事道具。** 礼卡、信封、香槟杯和聊天截图分别承担「可以送什么」「怎么添上心意」「收件人会看到什么」的解释。Hero 的蓝玻璃杯与后续实物礼品段呼应。同一套礼卡视觉又进入礼品类型、流程、余额和钱包。
- **页面用色块组织篇章。** 纸米色邀请进入，红色给礼物选择和发送流程定调，深咖放支付类能力和页脚，白色承接图多或信息密集的内容，灰蓝单独标记热门商品。背景变色大多随区块自然入场。流程的三步共用同一块红色，观众能把换图读成进度。
- **图片的变化集中在颜色、材质和比例。** 贺卡可斜放，信封可遮住一角，礼卡在卡槽或照片上叠印，聊天框保持手机竖幅。叠放的层次能读出物件关系，四周仍有清楚的边界和空白。
- **正文围绕一个常用动作推进。** 首屏承诺可以立即送礼，正文先解释选项再演示过程，然后让读者从具体场合、商品与口碑找到自己的理由。各处发送按钮回到同一类创作任务，弱入口留给了解、帮助和购物。

## Header 到 Footer

### 01 · 顶部商业提示与 Header

最上方约 40px 深咖栏用浅蓝 PRO 标牌、短句和了解入口引出企业送礼。桌面下层约 80px，纸米色背景，左侧字标，中间是 Personal／Business 和四个一级入口，右侧为白色登录与深咖送礼按钮。主导航在滚动中吸顶，商业提示条随首屏滚走。当前个人模式用实色胶囊表示，已有面向企业的分流入口，浏览者仍能立即进入一般送礼流程。

390px 下保留字标、主要行动和汉堡菜单。该页面的搜寻框位于桌面 Hero 内部，手机首屏的这个位置用简化礼卡展台承担。

### 02 · Hero 与首屏信任提示

纸面上先放搜索，随后用中央大标题把视线锁住，红字强调速度。桌面将礼卡、插画贺卡及打开的信封、蓝玻璃杯组合和现金卡放在标题四周，大小、倾斜角度和位置有变化。四组素材分别对应可送的内容，中央留出净空给文字、两种行动和五星提示。下半屏看到杯子与现金卡，读者带着已认识的物件进入下一段。

手机改用一张小礼卡与前后箭头集中展示素材，然后依次排标题、解释、企业引导和纵向按钮。第一屏更好读，但页面访问者需往下滑才能看到完整信任提示。主标题直说可做的事，副文案补充用途，五星只占很小一行。 [Givingli 首页](https://givingli.com/)

### 03 · Gift your way 礼物类型

红色全幅大标题像一道扉页，往下是三次明确的礼品选择。礼品卡在红底，左文右图，横向卡内有品牌和金额变化；实物段切回纸色，图文反向，蓝玻璃杯与礼盒用分离背景的陈列图；企业现金段换成深咖，搭配 Visa 奖励卡和重复字样的外层包装，标题旁明确标注 Pro。

三段都保留编号、短标题、解释与发送动作，以左右交换和底色区分用途。红卡的品牌与金额在等待时会变，实物照片负责真实触感，现金包装偏平面印刷。素材各有自己的表达方式，仍共用卡片尺度与暖色世界。 [礼物类型](https://givingli.com/#gifts)

### 04 · How It Works 三步流程

独立红色长段。桌面先用拉开字间分布的标题引入，再进入吸顶舞台。大数字、礼卡／贺卡／手机消息与当前说明在同一个舞台内更替。第一步展示可选礼卡，第二步换成贺卡与个性化素材，第三步显示短信送达与对方回复。舞台下方有前后箭头和发送按钮，实测下一步可从礼卡切到贺卡。滚动来到交接位置时，短暂能看到两组素材及文字叠在一起。

手机把三步恢复成顺序阅读，每步是数字、说明、对应画面，细线隔开三段。桌面步骤按钮在这个视口隐藏。红色贯穿全程，礼物从横向卡到纸品再到手机竖幅，媒介变化就是流程变化。 [流程演示](https://givingli.com/#how)

### 05 · Occasions 场合目录

切到白底、居中大标题，然后上场景封面。桌面以三列两行展示生日、随手送礼、爱意、庆祝、感谢和职场等主题。每张都是一组搭配，例如插画贺卡配一张品牌礼卡，再用柔和背景和叠放关系区分氛围。栏目名称在图上方，浏览动作贴在左下。六个更多场合在桌面排成一行文字链接，手机图集和文字链接都改成两列。

这一段承担从「我懂怎么送」到「我现在有什么场合」的意图切换。选品与贺卡先配成一组，再交给用户浏览，图片之间仍可比较。 [场合目录](https://givingli.com/#occasions)

### 06 · Givingli Cash

深咖双栏用一句话接住「不知道对方喜欢什么」。左侧奶油色大标题、简短文案、红色实心主按钮和轻量了解链接；右侧用红色金额卡与品牌礼卡上下对应，中间用极小文字和箭头指向兑换结果。同额在上下两张卡出现，读者能沿相同位置识别价值如何转移。

照片和背景在这里让位给金额、品牌卡面和对应关系。注意前面的 Pro Cash 章节讲企业支付产品，这里讲个人送礼可选的 Givingli Cash，标题和包装相似，但入口与能力归属分别说明。 [Givingli Cash](https://givingli.com/#cash)

### 07 · Gift Wallet

白底双栏，左侧用大标题解释收礼后的使用方式，三个短点在窄栏里说明积攒、拆分和随时使用。右侧是一张大的余额凭证和三张品牌小卡，金额使用等宽字体。实测等待时有不同品牌与金额组合出现，这是一组演示状态。大卡和小卡的比例，把「余额拆给多品牌」从两段说明变成一个清晰的关系图。

Givingli Cash 段解释送礼人如何给选择权，钱包段紧接着解释收礼人如何使用。它们共用礼卡作为主物件和金额作为识别线索。 [钱包](https://givingli.com/#gift-wallet)

### 08 · Real reactions 与独立手写引语

回到纸米色。第一块是可换项的回馈展台：左侧手机消息画面，右侧大字引语、编号与场合标识；试看到第一例使用灰蓝底，手机截图里仍有可识别的贺卡与礼卡。五个例子配有箭头和位置选择。报告只记录页面呈现的回馈。

然后拆掉大卡片外壳，在纸色留白上放独立手写引语、署名情境和一枚深色送礼按钮。两部分分工清楚，先给聊天语境，再把一句感受放大。手写体在这里模拟贺卡上的一句留言，因此还能接续前面的素材主题。 [用户回馈](https://givingli.com/#real-reactions)

### 09 · The Gift Note 内容栏目

红色作为章节入口，居中的大标题和一句介绍下方是一条深咖色横向文章轨道。卡片用封面、短标题、摘要和阅读链接，右侧边缘留方向操作，底部另有进入完整内容栏目的动作。这个段落从购买转成阅读，服从同一套纯色和胶囊按钮语言。

前几张封面分别使用品牌包装胶带、胶片感人物近照、纸张和手写字拼贴。三种主题沿用相近画幅与有质感的实物细节。快速跳到这里时曾看到空槽，停留后封面加载。这个区域属于内容运营，长线质感取决于封面能否持续遵守相同的构图和材质方向。 [Givingli 首页](https://givingli.com/)

### 10 · Shop Popular 热门选品

丹宁蓝全幅明确进入选品区。标题下方是贺卡／礼物切换，旁边有手写提示，接着是深咖横向展示轨道。贺卡视图下，可见多种插画作品、编号和设计者署名，卡面本身就是商品图，白色圆形箭头负责导航。礼物视图切换到另一组商品及浏览入口。

同样是横向图带，它和文章区的区别在于卡片信息更轻、图片形状更直接、关联的是选品入口。手机沿一条窄轨浏览，不把海报或卡面强塞成桌面密度。 [热门选品](https://givingli.com/#shop)

### 11 · Reviews 与媒体报道

评论段在短评墙与大幅媒体引语之间切换层级。星星、头像、短评和署名给出可扫读的应用体验，浅蓝、深咖和纸色控制密度。中间以大块引语和评价数量留出停顿，下面有 Forbes 名称和品牌创办人相关照片与拼贴。滚动中背景可见大幅图像变化，黑白照片作为深层背景，前景文字仍在相对稳定的纸色面板上。

前面的聊天满足「对方会怎么收到」，这里的评价回答「发送者用起来怎么样」，媒体背书又是独立一层信任。页面所给评分与数量来自品牌自述。 [Givingli 首页](https://givingli.com/)

### 12 · 收尾 CTA

整块红色留给一个情绪转折。第一幕是超大百分比及情感陈述，滚到后段换成简洁的送礼号召和深色胶囊按钮。两幕在同色背景中衔接，形成开头「能送什么」与结尾「现在给谁送」的一次闭环。

这类动效有效，是因为前面已经证明了送礼流程，结尾只需要重提行动。页面上的百分号以视觉修辞出现，缺少统计口径。 [Givingli 首页](https://givingli.com/)

### 13 · FAQ、社交展示与 Footer

FAQ 回到纸米色。桌面左列放超大标题、帮助中心入口，右列放深咖折叠条，覆盖兑换、是否需要 App、送礼、余额、活动与企业目录。手机按列堆叠。展开后答案在对应问题下出现。

真正页脚前还有一段浅色社交展示，中心是 `@givingli`，下挂五张图，统一导向 Instagram 账号。Footer 用单一深咖结束全页。在桌面，品牌符号、快捷链接、联系方式和社交链接并排；窄屏逐组向下排。超大白色 Givingli 字标出现在下部，最后一条细线隔开版权、隐私与条款。行业术语和复杂导航都很少，品牌名本身就是最后一张画面。 [Givingli 首页](https://givingli.com/)

## 图文搭配与滚动为什么连得起来

### 素材可按同一物件跨章节使用

礼卡在首屏承担识别，在礼物类型展示品种，在步骤里进入发送过程，随后以聊天附件的方式抵达收件人。制作素材时同步考虑四种形态：独立物件、可与其它物件叠放的透明或干净背景素材、带可辨识文字的单独画面、出现在结果界面里的对应状态。Givingli 的说服力来自这些形态能互相认出来。例如蓝色杯子从 Hero 走到实物礼物段，现金卡再流向兑换关系图。

构图要素也在重复。会移动的礼卡有清楚边界，配对卡片沿一个方向错开；纸品放置遵守实际遮挡与阴影；有整块文字时会为主体留一块净背景。场合封面可以鲜艳，外层章节仍有稳定主色让页面停得住。

### 整页滚动和局部动效各有职责

| 层次     | 实际观察                                                                 | 内容用途                                   |
| -------- | ------------------------------------------------------------------------ | ------------------------------------------ |
| 章节交接 | 纸米 → 红 → 纸米 → 深咖 → 红 → 白，后段再用深咖、纸米与丹宁蓝分场。      | 自然滚动暴露下一块背景，色边就是章节边界。 |
| 流程叙事 | 桌面有视口高的吸顶舞台，红底不动，文字和画面交替淡化。手机改成连续三步。 | 人在同一空间看见礼卡到收件画面的变化。     |
| 商品选项 | 礼品卡内品牌和金额轮换；热门选品、回馈与内容栏目有各自局部导航。         | 展示选择范围，允许人停下来查看单项。       |
| 情绪收束 | 收尾红区从百分比引语转换成单个发送按钮。                                 | 把阅读的情绪引回转化动作。                 |

在所查的首页文档里，没有发现嵌入式视频元素、Canvas 或 iframe。首屏和步骤的主要表达依靠静态或透明底商品素材、可变的卡面文字、聊天图像以及布局内过渡。视觉较弱的时刻集中在滚动交叠、跳到懒加载区块或停留在近似机制的多个轮播上；桌面步骤舞台整个红区约 3.7 个视口，手机单列全页也很长。读者到下一条信息的距离需要和内容价值相匹配。 [Givingli 首页](https://givingli.com/)

## 对照 Lycobo 电商专区

- **已确认的 Hero 是正文的起点。** 对照时优先比较现有 Hero 底部到问题与流程的第一屏，观察色面接缝，以及标题或同款商品是否能自然接过视线。当前页面规格见 [DESIGN 的电商专区](../DESIGN.md#5-品牌首页与电商专区)。
- **把跨段重复用在同一商品的身份上。** 在现有素材中找一组能同时辨认主体与变化的原图、成片、使用场景与特写。每张图的背景、光向、裁切、阴影留白，与所在区块一起看。工作台解释步骤，后续大图展示差异，套图以完整陈列和局部细节支撑同一用途。素材出处见 [专区素材](landing-assets.md)。
- **用版式和色彩安排停顿。** 品牌色承担行动和当前状态，产品本色承担视觉吸引力。版面可以在文字靠左、样片大图和成组小图之间改变节拍，用相同的内容边线串起一页。先选整体色面和画幅，再检查每组图片的色温与光线。
- **保留一个值得滚动展示的过程。** 只有原图到成片的关系需要驻留；在这个过程中保有原图或同款主体做视觉锚点。场景和套图的静态结果要能随时看清，窄屏优先让信息按阅读顺序出现。照片承担结果证据，操作短片的价值取决于它能否补足动作过程。
- **内容证据沿用实际产品能力。** Givingli 用聊天和作品目录说明品牌价值，Lycobo 对应的是可核对的同款样图、现有工具和真实工作区入口。范围见 [PRD 的导航与账户](../PRD.md#4-导航与账户)。

本文记录第三方首页的现状和设计拆解。Lycobo 的定稿规则见 [DESIGN](../DESIGN.md)。
