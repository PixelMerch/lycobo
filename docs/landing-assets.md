# 电商专区素材清单

本清单记录电商专区示例的来源。页面在 `/commerce`，实现位于 `apps/web/src/features/home/landing/`，现行视觉见 [DESIGN](../DESIGN.md#5-品牌首页与电商专区)。图片是展示素材，不代表客户订单、真实评价或在线生成。

参考沿革：早期版式参考 VidMuse winning-ads 与用户确认的 [Figma Make 原型](https://www.figma.com/make/SZ7mUN04H1uhrlbjGheg2D/Build-Lycobo-Ecommerce-Landing)。随后采用 Lovart 的成套作品组织、FLORA 的输入与结果关系、Recraft 的大图比例。保留 Lycobo 品牌、原有 Hero 和真实工具入口。参考用于构图和交互研究，第三方素材边界见[来源声明](third-party.md)。

- 生成工具：本地 `gen-image` 命令行工具（仓库外的素材流水线）
- 实际模型：`gpt-image-2.6-sunburst`
- 生成日期：2026-11-14
- 生产提示词：P01–P11 与对比图为项目既有生成素材；模板提示词维护在 `apps/web/src/features/home/landing/sections-messages.ts`。
- 存放目录：`apps/web/public/landing/commerce/`；网页使用 82% 质量的 WebP，原始 PNG 母图只留在本地生成目录。
- 裁切：案例和模板由 `object-fit: cover` 或 ImageMagick 安全裁切；未做旧图改名或截图复用。

## 正文占位与出图

以 [Givingli 首页设计拆解](givingli-landing-analysis.md) 中的同款物件、纯色章节和固定舞台为版式参考。Hero 使用原素材，正文暂用 CSS 画幅占位。下表是正式素材的配套方向，待按版式确认：

| 位置       | 画面关系                                                                                               |
| ---------- | ------------------------------------------------------------------------------------------------------ |
| 暖白引入   | 小幅原图、方幅棚拍、横幅杯盖特写。三张保留奶油白杯盖、透明杯身、圆形按钮和右侧挂绳。                   |
| 深底流程   | 主图框固定为 6:5，四步分别用原图、棚拍、自然光厨房和特写；主体居中，避免杯盖和底座在统一画幅中被裁掉。 |
| 商品场景   | 4:5 厨房环境配 1:1 浅色布景，主体比例与光向应可比较，两张背景的色温与暖白正文匹配。                    |
| 细节与收尾 | 4:3 大图，另配主图、杯盖及挂绳、杯身及底座、场景四个缩略图。收尾复用同款棚拍。                         |
| 模板       | 单图和三图组合先定占位比例，原有模板 ID 和提示词继续用于创作。                                         |

下面保留已有素材库及制作来源，供后续选图和生成核对。

## 未完成与边界

- 模板封面的提示词和最终构图在消息目录维护；未为每张封面单独提交新的付费生成任务，而是在对应母图的安全范围内裁切。
- 1.5K 与 4K 的差异只用契约计算出的输出尺寸表达，没有把低清图放大后冒充 4K 原图。
- P11 的模特为同一位成年虚构人物，细节图以母图和穿着图为参考；不同生成批次之间可能存在轻微差异，不能当作真实商品资料。
- 旧参考站媒体仍保留在 `apps/web/public/landing/`，供 Hero、背景和旧档案使用；商品展示引用 `commerce/` 目录；2026-11-14 家纺展示另复用 `studio/textile-views/` 四张同系列视角图，来源见 [家纺视角资源](textile-view-examples.md)。

使用内置 imagegen 工具，以项目 `p02-blender-hero.webp` 为参考生成，模型标识未由工具返回。新图均为同款便携榨汁杯的展示素材，不代表在线任务或真实客户结果。原始 PNG 保留在本地生成目录，网页仅使用1024×1024、质量82的WebP。

| 文件                   | 体积   | 用途                 |

| `p02-motion-sage.webp` | 约42KB | 鼠尾草绿厨房场景揭示 |

生成约束：保留奶油白杯盖与底座、透明空杯身、正面圆形按钮、右侧灰色挂绳和原商品构图；只更换背景、台面与对应光影，不加入文字、标识或界面。厨房用浅色石材、鼠尾草绿墙面与柔和叶影；影棚用暗梅色墙面、玫瑰石材与侧光。两张独立生成图存在细微轮廓差异，因此用场景揭示过渡，不作像素完全一致的承诺。
