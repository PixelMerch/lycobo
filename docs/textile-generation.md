# 家纺主图裂变

## 已实现的流程

入口 `/commerce/textile-set`。主图必填1张，详情图可选最多5张，支持多选与分批追加、单项替换／删除和清空全部详情图；用户选择1–10个不同视角、比例及1.5K／2K／4K分辨率。张数由视角数量确定，不新增模型／提示词／质量／张数控件。当前v5默认逻辑模型 `gpt-image-2.5`、标准质量，真实上游由后台渠道配置，每张2积分。1.5K正方形输出1254×1254，旧1K快照不变；尺寸适配与实测范围见[生图API](image-generation-api.md)。按钮显示总积分；确定失败逐图退款，未知收费结果按既有核对流程处理，不自动重复付费请求。

提交使用现有 `/image-assets`、`/image-tasks`：上传仅发生在点击生成后，第一参考为主图、第2–6张参考为详情图。静态角度示例从不作为参考图提交。鉴权、组织归属、幂等、任务与outbox事务、账本、存储路径和签名CDN沿用原链路。

一个任务包含N个子任务，对应N个有序视角。API在保存前替换客户端提示词、模型、质量、分辨率为服务端固定配置；Worker按子任务的稳定position读取视角预设，各请求 `n=1`，得到独立单图，避免一个多图请求重复同一构图。模板包含商品身份／颜色／花型／绗缝保留、详情图辅助规则、视角构图及禁止拼图文字水印；实际模型还原程度需真实图片验收，不能保证所有材质和花型都完全一致。

模板在 `packages/generation/src/textile-generation.ts`，元数据 textileSet.version 与有序 views 保存到任务。当前新任务使用 v5，逻辑模型 gpt-image-2.5，必须有后台 textile-set／gpt-image-2.5 路由才可提交，否则在扣款前拒绝，不能回落到旧 sunburst 别名。上游使用渠道快照中的 upstreamModel，每个视角固定一次 n=1 提交；第一张为主图，后续最多5张详情图，提示词仍由服务端带入。分辨率由渠道公开能力约束。

v1 保留原1张详情图规则；v2 允许5张详情图；v1/v2固定1K，v3保留旧gpt-image-2.5-sunburst通道与所选分辨率，v4保留gpt-image-2-4K。已接收任务、快照和旧版语义不变。升级后的确定失败视角须用户确认新任务；未知结果不自动切换渠道或重发。

## 历史与重试

`GET /image-tasks?tool=textile` 只分页裂变任务，`tool=create`只分页普通创作；省略tool保持旧的全部任务语义。筛选在数据库limit之前执行，不用前端过滤已分页结果。共享历史组件按工具使用独立缓存，SSE同步更新所有已加载历史缓存。当前图的角度按item.position映射，部分失败仍保留其他成功图片。

重新编辑恢复1张主图和全部详情参考、视角、比例与分辨率，不覆盖创作模型草稿。重新生成沿用任务确认弹窗；失败卡片hover／键盘聚焦提供单图重新生成，触屏常显，确认单张费用后调用现有retry接口并传itemId，只重试当前失败或待核对条目；任务头部入口不传itemId，仍批量重试失败项，成功图片保留，position不变。响应丢失时保留原请求与幂等键，刷新后“确认上次提交”原样重放，不能因为用户修改当前输入而新扣一次。

## 验证边界

自动验证使用隔离PostgreSQL、临时图片存储和注入的服务商fixture。不会调用外部付费模型，不写线上业务数据。真实床品主图的模型质量尚需使用明确测试账号与限额人工验收。

旧版家纺任务（v1–v4）中已明确失败的图片，用户确认后使用v5与当前后台裂变渠道创建新任务，仅包含选定失败视角并保留原记录。含待核对结果时仍使用原有核对／明确确认重试流程，不自动升级未知结果。普通创作与v5任务原位重试不变。

## FluxPort gpt-image-2.5 接入

按 [gpt-image-2.5 文档](https://uselg.top/docs?model=gpt-image-2.5&group_id=12&offer_id=media_427cdffbe8a55d7034e4c9ca033773db) 实现。JSON编辑使用 images[].image_url Data URI，不公开本地／私有R2源图。请求 response_format=url、async=true，同时接受200同步图片和202任务回执；优先按status_url轮询，兼容poll_url，成功后保存图片而非长期保存供应商链接。签名链接失效时仅回退到同一结果的受保护下载，不重提交。

供应商地址、凭据、上游模型与能力统一通过后台模型服务配置，前端不读取供应商参数。当前各分辨率是否可用以后台渠道为准，不能仅从价格档推断；参考图上限为本应用验证约束。

原环境变量导入脚本已退役；通过独立后台管理中转站、访问密钥、模型渠道和默认路由。运行时不再从 VAKV_* 环境变量回退。

隔离验证涵盖两个视角异步受理、重复消费、查询、存储、恰好扣款、请求ID保留及无配置时不扣费；不冒充新线路的真实付费验收。
