# 电商专区与参考页说明

电商专区位于 `/commerce`，实现位于 `apps/web/src/features/home/landing/`；品牌首页位于 `/`。视觉以 [DESIGN.md](../DESIGN.md#5-品牌首页与电商专区) 为准。

2026-11-16 按用户要求，通过 ego-browser 观察 [VidMuse winning-ads](https://vidmuse.ai/zh-CN/winning-ads) 从 Hero 到页脚的构图、图带与滚动节奏，重新组织电商专区 Hero 下方的内容。用户随后明确要求恢复 Hero，因此首屏完整保留修改前版本。参考的是照片的主次关系、开放留白与章节变化，不复制其文案、媒体或业务指标。

- Hero 的文案、输入框、平台选择、四组案例、平台预览和演示数据浮层完整保持修改前版本；本轮仅修改下方正文。
- 10 张模板图带提前承接 Hero。保留已有提示词、工具、登录返回与覆盖确认，循环副本不进入无障碍浏览或 Tab 顺序。图带悬停、聚焦、拖动、离屏与后台暂停，减少动态效果时只保留单组手动浏览。
- 三组商品原图／成片使用一段较短的原生固定滚动展示；画面从一开始就可见，只在章节交接时淡入。没有劫持滚轮或自动翻页。手机、短窗口和减少动态效果时直接展示全部三组。
- 家纺使用卧室全景与三个细节构成完整画册，服装使用穿着、拉链、面料和户外场景构成完整套图，均不再延长页面等待照片展开。各图继续用已有全屏图片浏览器查看。家纺来源见 [视角资源](textile-view-examples.md)。
- 复制爆款保留独立参考图与实际入口；输出规格保留比例、1.5K／2K／4K、目标像素、登录返回和草稿确认。比例预览不代表已经生成了新图，实际规格由工作区能力校验。
- CTA 回到首屏当前工具，页脚保留真实工具、素材弹窗和法律链接。没有添加社交账号、客户评价或性能承诺。

本轮复用项目原有 WebP 图片，没有调用模型重新生成素材，也不把案例当成客户成果。来源见 [素材清单](landing-assets.md)、[第三方材料](third-party.md)。旧 [DeepSeek 任务书](../ds.md) 只保留素材提示词与历史背景，其布局不再作为现行规范。

使用 ego-browser 进行参考观察和本地视觉检查，React 与 HeroUI 技能用于组件和交互约束，Impeccable 用于布局与内容精简。未升级依赖、改动项目技能快照或安装全局 hook。浏览器 E2E 仍只由 GitHub Actions 手动工作流执行。
