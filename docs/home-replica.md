# 电商专区与参考页说明

电商专区位于 `/commerce`，实现位于 `apps/web/src/features/home/landing/`。品牌首页位于 `/`。视觉尺寸、颜色和交互由 [DESIGN.md](../DESIGN.md#5-品牌首页与电商专区) 维护，素材来源见 [专区素材清单](landing-assets.md)。

- 专区 Hero 使用 React Bits Gradient Waves，并展示四组商品对比案例。平台界面与数据为本地演示。
- 通过顶部电商菜单选择工具。首屏创作框只做展示：加号入口、「复制爆款」标签、提示词输入、商品素材／图片规格标签和圆形发送按钮都进入现有工作区，不提交生成任务。
- 案例画廊为 10 张商品图示例：精华、运动外套细节套图、运动鞋、耳机、咖啡、托特包、香水、床品、宠物碗和杯碟。第二张宽卡由整体穿着图与六张细节组成，点击后复用全屏图片浏览器。
- 工作流改为商品素材、套图方案和制作图片：四张同款榨汁杯素材、原图／成片切换、五项方案，以及 12 张按用途分组的示例。
- 工作流第三步的图片规格行提供当前主图工作区支持的 8 种比例和 1.5K／2K／4K 分辨率；输出尺寸调用 `imageOutputDimensions`。点击「按此规格制作」只带入比例与分辨率，已有草稿确认后才改规格，不生成任务。
- Impact 使用同一款托特包的主图、场景和两处细节，数字为「1 款／4 张／3 类」，不表示投放收益。
- 模板共 10 张。主图类模板把模型提示词带入主图草稿；商品套图和多种背景带入套图计划；参考版式只打开复制爆款，家纺视角只打开家纺裂变。未登录时记住本次模板或规格，登录返回后继续。
- CTA 回到首屏创作展示卡。专区页脚改为图片创作、工作空间和法律三组真实入口；未配置地址的社交项只作静态标识。
- 本次案例、工作流、Impact 与模板图片位于 `apps/web/public/landing/commerce/`，均为 2026-11-14 用本地生图工具制作的示例，不代表用户结果或真实客户素材。
- 参考采集来自 Page Take 的 `guide/`、`manifest/` 与 `resources/`。平台示例以外的参考媒体仍须在发布前核对再分发权利。Gradient Waves 来源见 [第三方材料](third-party.md)。
