# 首页复刻页说明与改进建议

更新：2026-11-12。

本文记录当前首页复刻页的范围、与采集源的差异，以及后续改进建议。它描述的是**视觉原型**，不是生产能力说明；正式上线前仍需产品、视觉和法务确认。`DESIGN.md` 仍是全站视觉规范，本页目前是用户明确要求下的临时例外。

## 当前状态

- 首页路由 `/` 渲染 `apps/web/src/features/home/landing/landing-page.tsx`，应用壳提供真实 Header，页面保留独立页脚与首页内容区主题。
- 首屏使用荧光绿 `#A8FF00` 与薄荷 `#54E6A5`，其余区块暂用采集页橙红 `#FB5123`（悬停 `#FC744F`）；页面底色为黑色。
- 媒体资源在 `apps/web/public/landing/`，组件和样式在 `apps/web/src/features/home/landing/`。
- 首屏使用 React Bits Gradient Waves 的缎面光波背景，黑底上以荧光绿／薄荷波峰作局部光，默认光带集中在左上角；位置、颜色和速度在 `gradient-waves-config.ts` 的 `focusX／focusY` 等字段中调整。WebGL2 不可用时回退为深绿渐变，遵循 `prefers-reduced-motion`。
- 首屏四组示例为焦糖橙床品、女装、小家电、护肤精华，按 TikTok Shop、Amazon、Temu、Shopify 切换；平台 UI 是本地预览 mockup，商品图是生成素材。
- 左侧使用一体式玻璃产品上传卡：64px 上传块、100px 场景输入、底部胶囊与 40px 圆形生成按钮；演示版只提示生成能力接入中，不提交真实任务。
- 内容区的上传、生成和计费目前没有接入业务；只保留页签切换、轮播、视频播放、点赞、模板填入等展示交互。
- 旧首页的创作框、模式页签、灵感墙和快捷入口组件已移除；灵感库、登录等仍被其他页面使用的代码保留。

## 改进建议

### P0：上线前必须确认

1. **把参考站文案换成 Lycobo 真实能力**
   当前页面仍保留竞品广告研究、Campaign Kit、ROAS、Lower CPA 等参考站演示内容。上线前应改为 Lycobo 的商品图能力，或明确标注为演示数据，不能把尚未实现的能力写成产品事实。

2. **确认素材和第三方运行时授权**
   采集页的图片、视频和 Logo 属于参考素材。正式发布前确认再分发权利；其中 4 张补充模板图来自现场素材源，同样需要复核授权。

3. **确定首页壳层与品牌决策**
   首页已接回 Lycobo 顶部栏，保留 C 款字标和独立页脚。

### P1：视觉与交互保真

4. **确认首屏场景授权与发布方案**
   首屏已改用 React Bits Gradient Waves；其 MIT + Commons Clause 授权与固定 commit 记录在 `docs/third-party.md`。模板图和采集素材的再分发授权仍需确认。

5. **补齐工作流的可访问语义**
   采集页使用 `role=tablist` / `role=tabpanel`；当前实现用 ToggleButtonGroup 完成视觉切换。建议改成 HeroUI Tabs 或补全 tab 语义、方向键切换和 `aria-controls`。

6. **复核响应式与减少动态**
   固定按采集视口 `1440×900` 和手机 `390×844` 目测；检查两侧黑边、Impact 内缩、模板横向滚动和所有动画在 `prefers-reduced-motion` 下的静态回退。

7. **恢复页脚微信入口的弹层行为**
   采集页的微信图标是带 `aria-expanded` 的弹层按钮，当前是普通链接。若保留社交入口，应改成正式 Popover 或明确标注为不可用。

### P2：接入真实业务

8. **创作框接入项目能力**
   将输入框、参考图、模型/比例设置和提交按钮接到项目草稿、登录门禁、上传、积分和任务提交；未接入前不要显示“已开始生成”等成功提示。

9. **导航、CTA 和语言切换接入项目路由**
   把内容区的模板 Remix、Start Creating 与 Try Now 接到真实页面；切换语言时保留首页状态，并补全中英文案目录。

10. **补齐页面元信息**
    根据最终内容设置页面标题、描述、OG 信息和主题色；不要把采集页的统计脚本、像素或第三方分析代码带入项目。

### P3：性能与验证

11. **压缩首屏媒体**
    当前公开资源约 12 MB，含多段视频。上线前按视口生成响应式图片、延迟加载非首屏视频，并评估首屏 Canvas 与视频同时播放的 CPU/GPU 成本。

12. **建立视觉回归基线**
    通过手动 GitHub Actions 浏览器 CI 覆盖首屏、工作流、模板轮播和 Impact 的关键断点；本地不运行浏览器 E2E。断言重点放在布局尺寸、可见状态和 reduced-motion，而不是像素级截图。

13. **清理原型残留**
    在功能接入后复查 `features/home/landing` 的未使用交互、重复媒体和临时样式；不要保留无法说明来源的素材或演示接口。
