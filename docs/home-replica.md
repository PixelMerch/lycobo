# 电商专区与参考页说明

电商专区位于 `/commerce`，实现位于 `apps/web/src/features/home/landing/`；品牌首页位于 `/`。视觉以 [DESIGN.md](../DESIGN.md#5-品牌首页与电商专区) 为准。

2026-11-16 根据用户确认的 [Figma Make 原型](https://www.figma.com/make/SZ7mUN04H1uhrlbjGheg2D/Build-Lycobo-Ecommerce-Landing) 落地 Hero 下方内容；导航与 Hero 保持不变。原型参考 VidMuse 的彩色背景、卡牌层次与展示节奏，产品能力和素材仍以本项目为准。

- 商品画廊保留真实模板草稿与登录门禁；新增可操作的暂停／继续按钮，离屏和后台仍暂停。
- 商品原图与成片按滚动进度切换精华、榨汁杯、外套；家纺／服装在同一舞台内自动切换，向上回滚可回看。手动选择仍可用，不拦截滚轮。
- 套图使用项目真实多视角图片，扇形细节卡只负责展示，独立视角按钮控制大图。沿用已有全屏图片浏览器。
- 参考构图区保留复制爆款真实入口。旧规格表单改为三段连续商品演示：素材列、两种场景、整套画幅；滚动自动推进，手动选择立即定位，入口进入套图工作区，不改写已有草稿。
- 减少动态效果时禁用过渡位移；滚动阈值仍更新内容。桌面、手机和短窗口使用对应舞台尺寸。

连续演示复用项目 WebP，包括2026-11-16以商品母图生成的两张场景素材；本轮没有新增生图调用，不把案例当成客户成果。来源见 [素材清单](landing-assets.md)、[第三方材料](third-party.md)。现行布局依据为 DESIGN 与上述原型。

使用 ego-browser 进行参考观察和本地视觉检查，React 与 HeroUI 技能用于组件和交互约束，choreograph 与 animate 用于卡片关系和动效编排。未升级依赖、改动项目技能快照或安装全局 hook。浏览器 E2E 仍只由 GitHub Actions 手动工作流执行。
