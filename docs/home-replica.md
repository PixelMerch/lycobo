# 电商专区与参考页说明

电商专区位于 `/commerce`，实现位于 `apps/web/src/features/home/landing/`。品牌首页位于 `/`。视觉尺寸、颜色和交互由 [DESIGN.md](../DESIGN.md#5-品牌首页与电商专区) 维护。

- 专区 Hero 使用 React Bits Gradient Waves，并展示四组商品对比案例。平台界面与数据为本地演示。
- 通过顶部电商菜单选择工具。展示卡只显示工具用途和工作区入口，创作在现有工作区内完成。
- 保留 Hero 下方的案例画廊、工作流、模板、CTA 与专区页脚。模板可带入主图草稿，覆盖前需要确认。
- 参考采集来自 Page Take 的 `guide/`、`manifest/` 与 `resources/`。平台示例以外的参考媒体仍须在发布前核对再分发权利。Gradient Waves 来源见 [第三方材料](third-party.md)。
