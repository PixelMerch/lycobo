# 任务完成后自动下载

用户明确要求自动下载时，在豆包「本地电脑」中选定一个目标目录，定时任务保存这项选择。参考图目录可以与下载目录不同。普通提交跳过本节。

1. 用本轮已受理任务的 `id` 一次调用 `prepare_task_downloads({taskIds})`，每批最多 20 个。补下已有任务也可使用任务编号，无需重新生图。
2. 将工具的 JSON 原样通过标准输入传给 `python3 scripts/download_task.py <下载目录>`，目录作为独立参数。收到 `started` 后，可回复已登记自动下载并结束本轮。凭证不出现在对话或日志里。
3. 脚本本机批量查询任务，只下载已完成任务的原图。每套保存到 `Lycobo-任务编号`，部分成功时保存已有原图。整台电脑并行最多 3 张。同一任务的已保存文件自动跳过。
4. `restartResume: true` 表示已启用 macOS 当前用户登录恢复。电脑开机登录后会继续未完成的下载，凭证最多有效 7 天。其他场景可运行 `python3 scripts/download_task.py --worker` 继续本机队列。凭证过期或更换 Key 后，重新为已有任务领取凭证。失败原因记录在任务子目录的 `.lycobo-download.json`。
