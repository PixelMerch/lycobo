# Lycobo 企业生图

使用 Lycobo 连接器提供的 `generate_image` 和 `get_image` 工具。需要配置连接器时，引导用户在 Lycobo 的「个人中心 → API 与技能」复制 MCP 地址，并把 Key 填入连接器的 Bearer 鉴权设置。

1. 从用户需求提取图片提示词和分辨率。支持 `1.5K`、`2K`、`4K`，用户未指定时用 `2K`。每次提交生成一张方图。
2. 一次生图或一次定时触发使用一个新的 UUID 作为 `requestId`。网络异常时，重复同一次提交必须复用该 UUID。下一次定时触发使用新的 UUID。
3. 调用 `generate_image` 并保存任务 ID。用 `get_image` 查询结果。任务仍在运行时，按 `retryAfterSeconds` 等待，当前执行最多查询三次。仍未完成时返回任务 ID，供后续查询。
4. 成功时返回下载链接及有效期。任务失败、内容审核拒绝或积分不足时说明原因，结束这次执行。收到限流时按服务端提示等待，超过当前执行时间就返回状态。

创建定时任务前，向用户确认频率、时区、提示词和分辨率，并说明每次生成一张图按 Lycobo 的积分规则计费。Key 由连接器保存，任务说明和对话都无需填写 Key。
